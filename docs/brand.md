# MindFlow 品牌视觉

2026-10-18 确认采用 **03 / Grow「灵感生长」**：两片叶芽与向上舒展的茎，表达一个学习问题逐渐长成结构化知识。保留已确认概念稿中的圆润 `MindFlow` 字标与蓝色。

## 使用原则

- 品牌蓝：`#3F63E6`，用于 Logo 叶芽及品牌强调；默认实心按钮采用下文独立的深浅主题配色。
- 浅色背景字标：`#101B38`；深色背景字标：`#F4F6FC`。
- 图形与字标均为 SVG 路径，不依赖系统字体、不内嵌位图。
- 横版标志按原比例缩放；外部至少保留标志高度四分之一的空白，不拉伸、不添加描边、阴影或渐变。
- 横版标志建议高度不低于 32 px；更小空间使用独立图标。独立图标可用于 16–64 px 场景，应用图标使用蓝底反白版。
- Logo 资产与界面配色分别验收；不因调整按钮颜色而改变 Logo，也不改变课程功能。

## 按钮配色

默认实心按钮（如「开始生成」）遵循以下规则：

- **浅色模式**：深蓝底 `#101B38`，与 Logo 字标墨色一致；白色文字与图标 `#FFFFFF`。
- **深色模式**：白底 `#FFFFFF`；黑色文字与图标 `#111111`。
- 悬停、按下、聚焦和禁用态沿用按钮组件既有的反馈方式，并以对应主题的底色与文字色为基础。
- 次要、描边、透明、链接和危险操作按钮保留各自的视觉层级及语义，不统一铺成实心按钮。

首页「开始生成」与大纲编辑器「确认大纲」已按本节同步，使用独立的 `action` / `action-foreground` 语义色；共享 Button 提供 `action` 变体。其余按钮和品牌强调色不在本次调整范围内，原有禁用与提交中行为保持不变。
