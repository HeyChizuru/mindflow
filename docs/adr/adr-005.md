# 大纲何时入库

## Context

课堂在创建时已经持久化。大纲与授课语言指令在确认前只活在生成页：流式生成、生成失败和手改都不把它们写成可恢复的事实。产品意图把确认前视为草稿课堂，确认后视为本课定稿。若在流式结束时就入库，刷新会带回用户尚未确认的大纲。

## Decision

- 用户确认大纲之前，不把大纲或授课语言指令写入数据库。
- 用户确认大纲时，才把当时页面上的大纲与授课语言指令写入该课堂。
- 确认前刷新或凭课堂 id 再次进入，只恢复已保存的课堂需求与资料。

## Consequences

- 大纲流与手改路径不得写入大纲或授课语言指令。
- 确认大纲的单元负责这次写入。写入之前，页面上的大纲与手改在刷新后不保留。
- 改为流式结束即写入，或确认后仍不写入，须替代本 ADR。
- 库存注释若仍写「SSE 完成后写入大纲」，是文档漂移，须与本决定对齐，不改变决定本身。

## Alternatives considered

- 流式结束即写入：刷新会恢复尚未确认的大纲，与「确认后才定稿」冲突，拒绝。
- 大纲始终不入库：确认后的大纲无法按课堂恢复，拒绝。
