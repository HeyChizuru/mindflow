# 产品意图

## 一句话

MindFlow 面向自学者与培训场景：用户填写**必填的课程提示词**、**可选的昵称与背景**、**可选上传 PDF** 作为参考资料后，系统生成由幻灯片与测验组成的结构化互动课程；用户可在课堂中观看讲稿字幕、完成测验，并与三名固定 Agent 讨论。无 PDF 时由模型依据提示词生成内容；有 PDF 时在入库后，大纲与讨论可结合文档检索。课程与生成结果持久保存在 PostgreSQL，用户重新进入仍可继续查看与播放。

## 给谁

- **自学者**：输入「我想学 XX」等需求，无教材也能生成可播放课程；有 PDF 时讨论可引用原文片段。
- **教师 / 培训者**：用提示词定教学目标与风格，可选上传讲义 PDF，生成带测验的课堂。
- **开发者（展示 / demo）**：需要一条可演示的全栈路径（生成、播放、讨论、可选 RAG），用于作品集或技术验证。

## 首个可交付功能集

配置模型（顶栏设置）→ 创建课堂（课程需求 + 可选昵称与背景 + 可选 PDF）→ 若有 PDF 则完成入库 → 流式生成课程大纲 → 手改并确认大纲 → 生成首屏场景并进入课堂 → 字幕播放 slide / quiz（含简答批改）→ 固定三名 Agent 课堂讨论（有 PDF 时回答附带文档引用）→ 后台续生成其余场景 → 通过刷新或历史入口重新进入，仍可恢复课程与已生成内容。

## 明确不做

**产品能力（当前版本不提供）**

- Pro 幻灯片编辑、TTS / ASR、AI 图 / 视频生成
- interactive / PBL 场景类型、联网搜索
- 课堂 zip / PPTX 导入导出、复杂 Roundtable UI
- 多 Provider 大型设置面板（MVP 使用精简设置弹窗）
- autonomous 模式、跨标签页编辑锁

**编排与 Agent 平台**

- OpenMAIC Pro Agent Runtime（如 pi-agent-core、持久化 Workbench Session）
- Agent 人设自动生成（`agent-profiles` 等）
- **M2+** 大纲编辑助手（Tool Chat 侧栏改大纲）
- **Phase 2** 冻结 Plan、Planner / Drafter / Critic / Director 评审闭环、`replan`、Plan 表格与 Round 评审 UI

**边界说明**

- 不在首个功能集中承诺「以后 Phase 2 / M2+ 会接」的能力；当前演示路径须完整走通，无需口头补洞。



## 主路径

1. 进入首页，填写课程需求（必填），可选填写昵称与背景，可选上传 PDF。
2. 创建课堂并进入生成预览页。
3. 若上传了 PDF，完成文档入库并看见明确的处理进度。
4. 看见大纲流式生成；可在确认前手改大纲标题、描述、要点等。
5. 确认大纲，触发首屏场景生成。
6. 进入课堂：按讲稿字幕播放 slide / quiz，并完成测验（含简答批改）。
7. 向三名固定 Agent 提问；若该课堂有关联 PDF 知识库，回答中应能展示文档引用，无 PDF 时不强制引用。
8. 刷新页面或通过首页历史列表再次进入：已持久化的课堂与生成内容仍可访问；失败时展示可理解的错误信息并允许重试。



## 怎样算成功

- 目标用户按上述主路径能**独立完成**从建课到播放、讨论的核心任务，演示时**无需**解释「这里以后会接」。
- **无附加 PDF** 与 **提示词 + 可选 PDF** 两种输入模式均可走通。
- 有 PDF 且入库成功时，课堂讨论应能展示引用来源；无 PDF 时仍可基于课程与提示词讨论，且不假装有文档引用。
- 重新进入后，已持久化的课堂、场景与聊天等数据仍可恢复（对齐「恢复测试」：刷新或再次进入不丢已保存进度）。
- 具体耗时、比例类指标在功能规格与验收证据中定义，不在本文展开。
