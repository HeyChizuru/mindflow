# 课堂播放与测验

## 目的与闭环

「确认大纲并生成首屏」已经保存第一场景的内容与含讲稿的动作。本单元让这些生成结果成为用户可以观看、操作和恢复的课堂，而不止是生成完成提示。

功能闭环为：**进入已定稿课堂 → 观看画布与顺序讲解 → 在测验中提交答案并得到反馈 → 切换已就绪场景或到达当前可播放内容的末尾 → 刷新或重新进入后恢复已保存内容、场景位置与答题结果。**

硬依赖只有「确认大纲并生成首屏」。即使「后台续生成」与「课堂讨论」尚未交付，也能使用已经保存的首场独立验收播放、答题与恢复；单场测验可独立验收三类题型。其余场景陆续保存后的衔接，以及真实 Agent 讨论，另做跨单元联调，不用本单元完成代替整条产品主路径完成。

## 承诺

### 进入课堂与内容来源

播放页路径确定为 `/classroom/[id]`，其中 `id` 为已持久化的课堂 ID。生成页首屏完成后的「进入教室」落到本页；用户也可凭同一地址再次进入。

页面读取同一课堂的已确认大纲、已保存完整场景、上次保存的当前场景和已提交答题记录。课堂目录以定稿大纲为顺序与总数依据，以已保存完整场景判断是否可播放；不把只有大纲或只有内容的半成品当作完整场景。

首次进入从第一场景开始；已有有效播放位置时恢复该场景。保存的位置已失效时回到第一场景并提示。草稿课堂或已定稿但缺少完整首场时，说明尚不能播放，并提供返回该课生成页的入口。本页不重新确认大纲、不补生成首场。课堂不存在或 ID 无效时展示明确错误，不创建替代课堂；读取失败时允许重试读取。

读取、渲染、播放和选择题判分不要求模型配置，也不因 PDF 或知识库状态受阻。简答批改才需要当次请求的对话模型配置；后台生成和讨论各自校验其配置。

### 幻灯片与讲稿播放

幻灯片按已保存画布的比例、背景、元素顺序、位置、尺寸、旋转和已有样式呈现。支持当前生成链路承诺的文字、形状、线条、图表和公式；文字保留已有排版，图表展示已保存的数据，公式显示为公式。窗口缩放时等比适配，不为适配窗口重新生成或改写内容。

本单元不增加图片、视频来源或媒体生成能力。遇到无法识别的元素、图表数据或无法显示的内容，明确标出该部分无法显示并保留其他可用内容，不以空白或伪造图形冒充完整渲染。生成内容中的 HTML、样式与公式只能作为受控展示数据，不得执行脚本。

动作按保存的数组顺序执行。进入或恢复场景后先停在待播放状态，由用户开始；支持播放、暂停、继续、下一段讲稿与从头重播本场。`speech` 的文字作为字幕显示，自动播放时给出可阅读的停留时间，再推进后续动作；不合成语音、不依赖音频时钟。暂停时保留当前字幕与画面效果，停止自动推进；手动下一段时，仍须按顺序执行两段讲稿之间的动作，不直接跳过。

- `spotlight` 聚焦对应元素，`laser` 指向对应元素；效果随画布缩放保持对齐。聚焦保持至后续同类动作替换或本场结束；激光是短暂提示。
- `widget_highlight` 高亮本页元素或题目，`widget_annotation` 在对应目标旁展示标注；无标注文字时只提示目标。后续动作可更新效果。
- `widget_setState` 更新本场临时教学状态，并在教学提示区展示可读的状态键值；它不表示可执行程序，不操作任意页面控件，也不修改学习者答案、判分结果或持久化场景。
- `discussion` 展示已保存的话题与引导并暂停自动播放，用户可继续后续讲解。本单元不调用 Agent；「课堂讨论」接入后由其负责真实对话，用户结束讨论后仍能继续本场。

本场动作执行完后停在「本页讲解结束」，不自动翻页。重播从本场第一条动作重新开始；切场、重播、离开页面时清除旧场景的字幕、临时教学状态、效果和自动推进，旧异步回调不得改变新场景。重播不清除已提交测验结果。

动作无法识别或目标失效时，展示该动作无法执行的提示并允许继续；不执行任意脚本，不因单个异常动作锁死整个课堂。

### 场景切换与内容未就绪

用户可以上一场、下一场，或从文字目录选择已经就绪的场景，顺序沿用定稿大纲，不修改标题、类型或顺序。切换成功后保存当前场景位置；保存失败时明确提示位置尚未保存并允许重试，不能承诺刷新可恢复这次位置。

尚未保存完整内容的目录项标为未就绪且不可播放。下一场未就绪时保留当前场景，说明后续内容尚未就绪并允许重新读取；不能跳入空场景，也不能把「当前只有一场可播」显示成「整课已结束」。用户仍可回看其他已就绪场景。

本页是「后台续生成」的承载页，但生成启动、选场、排队、模型调用、生成重试和整课生成状态均归该单元。本单元只消费其保存的完整场景；新内容就绪后更新目录可播放状态，不打断当前讲解、答题或讨论，也不自动切场。后台生成失败不影响已保存内容继续播放。

全部大纲都有完整场景，且用户到达最后一场并结束本页讲解时，显示「已到课程末页」，保留回看和返回首页入口；如仍有未完成批改的测验，提示其位置。到达末页不代表所有题目已作答或已经掌握课程。本单元不计算整课学习完成率、合格状态或颁发证书。

### 测验作答与反馈

测验展示已保存的题目，支持单选、多选、简答三种题型。讲稿与题目可同时观看；未提交时不主动展示正确答案、参考解析、评分依据或得分。允许跳过测验先看其他已就绪场景；不强制答对才能继续。

以单题为提交与反馈单位：单选只能选一项，多选可以选多项，简答输入非空文字。无有效作答时禁止提交；提交期间防止重复操作。客户端传入的课堂、场景、题目及选项必须属于本次课堂的已保存内容，不能用客户端传来的答案标准、分值或评分依据判分。

选择题由服务端按已存正确答案确定结果：单选一致得该题满分，多选的选项集合完全一致得满分，顺序不影响；错选、漏选或多选均为零分，不做部分得分。返回用户答案、对错、得分、满分、正确答案与已存解析，不调用模型。

简答题先保存用户提交的原文，再基于该题题目、参考解析、评分依据和用户答案请求对话模型批改，返回得分、满分与有针对性的评语，并展示参考解析。得分必须在零至该题满分之间；模型返回缺失、格式错误或越界分数均为批改失败，不将其当作零分或成功结果。本次批改不检索 PDF，不要求向量模型，不启动多 Agent 讨论。

简答批改未完成时显示处理中；缺少对话配置、模型请求失败、超时或结果保存失败时，保留已保存答案并显示待批改或批改失败，允许对这份答案重试。不得用模型回复已到达代替结果已保存。刷新后先读取已存结果；已有结果直接恢复，只有仍无结果且用户请求重试时才重新批改。

### 答题保存与恢复边界

本版本无登录。当前场景位置和答题记录归课堂所有，持有同一课堂 ID 的页面读到同一套已保存记录；不按昵称、浏览器或访问者分别建立学习档案。

每道题保留一次有效提交及其最终结果。答案一旦成功保存便锁定，批改失败只重试原答案，不改答，不新增刷分记录；提交前允许自由修改。本版不提供重做、历史尝试比较或清空答题记录入口。

重复提交、连续点击或响应丢失后重试，不覆盖已保存答案，不追加重复结果；重新读取返回已保存记录。多个页面提交同题时以首先成功保存的答案为准，后到页面恢复该答案并说明已提交，不把另一份输入覆盖进去。进行中的简答批改不被一次普通重试重复启动；过期或失败的批改可以重试，旧请求不得覆盖已经保存的最终结果。此规则不要求跨标签页编辑锁。

已提交答案、批改状态与结果持久化到 PostgreSQL；刷新或凭课堂 ID 再次打开可以读回。普通播放恢复到上次保存场景的开头并等待用户开始，不承诺恢复精确动作索引、字幕时间、临时画面效果或自动播放状态。未成功提交的输入只保留在当前页面会话，切换场景回来仍可继续编辑；刷新、关闭页面后不承诺恢复，切换课堂时不混用。

答题保存失败时保留当前输入、展示可重试错误，不显示「提交成功」。位置或批改保存失败不改写生成结果，不回滚定稿，也不阻塞已经可读的课堂内容。

## 非目标

- 不生成、编辑、重新排序或覆盖场景、大纲、讲稿；不承担后台续生成及其状态调度。
- 不实现三名 Agent 对话、聊天持久化、文档引用或复杂 Roundtable UI；讨论入口和真实对话由「课堂讨论」交付。
- 不提供 TTS、ASR、音频同步、视频播放、图片生成、PDF 图片提取、白板、interactive 或 PBL 场景。
- 不提供幻灯片编辑器、缩略图生成、导入导出、联网搜索、Tool Chat、Plan 蓝图或评审闭环。
- 不提供登录、多人独立成绩册、教师评分管理、考试监考、防作弊、错题本、重做、整课总分或学习统计。
- 不提供模型设置界面，不改首屏生成的模型配置来源；仅约定简答批改使用当次请求的对话配置。
- 不新增首页历史列表，不承诺未提交输入或精确播放时间的跨刷新恢复。

## 验收

- CP-1 WHEN 首场完整保存后用户点击「进入教室」，或凭该课堂 ID 打开 `/classroom/[id]`，THE SYSTEM SHALL 读取并展示同一课堂的内容、目录和当前场景；首次从第一场开始，已有有效位置时恢复该场景。草稿或缺完整首场时提供返回该课生成页的入口，不在本页生成；无效 ID、课堂不存在或读取失败时给出相应错误与可用恢复入口。
- CP-2 WHEN 播放已保存的幻灯片，THE SYSTEM SHALL 展示文字、形状、线条、图表与公式及其保存的布局、样式、背景和层次，窗口缩放后比例及动作目标仍对齐。无法显示的内容有明确提示，其他内容仍可用，不执行生成内容中的脚本，不调用模型重建画面。
- CP-3 WHEN 用户开始、暂停、继续、跳到下一段或重播本场，THE SYSTEM SHALL 按保存顺序执行动作并展示可阅读的讲稿字幕，暂停时停止自动推进；下一段不跳过中间动作，重播从第一条开始。本场结束停留，切场或离开后旧计时与回调不继续生效；全程不合成语音。
- CP-4 WHEN 动作包含聚焦、激光、组件高亮、组件状态或标注，THE SYSTEM SHALL 按本 spec 的语义展示对应效果或教学提示；讨论动作展示话题与引导、暂停并允许继续，不要求真实 Agent 才能播放。未知或失效动作有提示且可继续，动作不改用户答案或判分结果。
- CP-5 WHEN 用户上一场、下一场或选择目录，THE SYSTEM SHALL 只进入本课堂已保存完整内容的场景，并保存当前场景位置。目标尚未就绪时保留当前场景、提示并允许重读；有未就绪场景时不宣称整课结束。全部场景就绪且最后一场讲解结束时显示到达末页，可回看或返回首页，并提示未完成批改的测验。
- CP-6 WHEN 用户提交单选或多选答案，THE SYSTEM SHALL 校验题目与选项归属，以服务端已存答案判分；完全正确得满分，否则零分，多选顺序不影响。保存成功后展示该题答案、对错、得分与解析；未提交时不主动揭示这些内容，判分不调用模型。
- CP-7 WHEN 用户提交有效简答且当次请求有可用对话配置，THE SYSTEM SHALL 保存原答案并依该题评分依据批改，保存有效结果后展示范围内得分、满分、评语和参考解析；不要求向量配置或 PDF 检索。缺配置或模型结果无效时不得冒充批改成功。
- CP-8 WHEN 答案保存、简答模型调用或结果保存失败，THE SYSTEM SHALL 区分提交失败与已提交待批改，保留相应输入或已存答案并允许重试；只有已保存结果才能显示成功。结果已保存但响应丢失时重读同一结果，不重新批改；仍无结果时只对已提交答案重试。
- CP-9 WHEN 同题重复提交、连续点击、批改中重试或多个页面竞争提交，THE SYSTEM SHALL 保留首先成功保存的唯一答案与至多一份最终结果，进行中不重复启动批改，旧请求不覆盖最终结果；后到页面恢复已保存记录，不用新输入覆盖。已提交题目不可改答或重做，重播不清除结果。
- CP-10 WHEN 用户切场后返回、刷新或凭同一课堂 ID 再次进入，THE SYSTEM SHALL 恢复已提交答案及其批改状态和结果；会话内未提交输入在切场后可继续编辑。刷新后恢复到上次成功保存场景的开头并等待开始，不自动重播、不自动重新批改；保存位置失效时退回首场并提示。
- CP-11 WHEN 用户没有模型配置，或知识库不可用，THE SYSTEM SHALL 仍允许读取、播放、切场、回看已保存结果及提交选择题；简答配置错误只阻止本次批改，不阻塞其他课堂操作。错误信息不包含密钥或堆栈。
- CP-12 WHEN 「后台续生成」保存了后续完整场景或报告生成失败，THE SYSTEM SHALL 在内容刷新后更新对应目录的可播放状态而不重置当前字幕、答题输入或已保存结果；已就绪场景继续可用，不自动翻页。本单元不发起或重试生成请求。此项在该单元交付后做跨单元联调，交付前可用顺序保存的完整场景验证消费行为。
- CP-13 WHEN 场景、题目、选项或播放位置不属于该课堂，或客户端试图提供判分标准与结果，THE SYSTEM SHALL 拒绝非法读写，不修改其他课堂记录，不接受客户端指定得分；切换课堂后旧请求不得覆盖当前课堂展示。

## 系统不变量

- 场景仅有 `slide` 与 `quiz`；可播放内容以本课堂已持久化的完整场景为准，定稿大纲只提供课程结构与顺序。
- 本单元读取并播放生成结果，不改写大纲、场景内容、动作或整课生成状态；播放位置不充当生成调度指针。
- 播放状态与临时教学效果可在浏览器；需要刷新恢复的场景位置、已提交答案与批改结果以 PostgreSQL 为准，不把浏览器缓存当唯一事实来源。
- 判分标准取自服务端已保存题目，答题记录必须关联本课堂的真实场景与题目；所有读写按课堂隔离。
- 同题答案提交成功后锁定，失败批改不等于零分，已有最终结果不被重试覆盖。
- 对话 Key、端点、模型名只来自当次请求，不读服务端环境变量兜底，不持久化到课堂或答题记录。模型调用经统一对话封装。
- 无登录，持有课堂 ID 即可访问同一课堂与答题记录；不因可选昵称而承诺用户隔离。
- 到达课程末页、所有场景生成完成、测验全部批改完成是不同事实，不相互替代。

## 非功能约束与验证

- 基本播放、字幕推进、目录、作答与提交可用键盘操作；状态与错误不只靠颜色表达。
- 深浅主题和窄屏下主要内容、字幕、题目、反馈及控制入口可读可操作；画布保持原始内容配色，不随界面主题改写场景。
- 读写与批改都有明确进行中、成功或失败状态及恢复入口；不无限自动重试，不将普通读取失败当作场景未生成。
- 按 CP-1～CP-13 核对页面与持久化读回结果。覆盖首场为幻灯片和三类测验、有无 PDF、混合场景、部分内容就绪、重复提交、批改失败与刷新恢复；已有内容的播放与选择题判分应能在无模型配置下通过。
- 本文为待确认草案，尚无实现或验收结论；不以文档完成标记功能已交付。具体阶段、文件、接口、表结构及操作步骤留到后续 plan / task，本次不展开。

## 关系与归属

- 硬能力依赖：[[确认大纲并生成首屏]]，提供定稿课堂、完整首场与进入教室入口。本单元交付后补齐实际 URL 落地的跨单元验收。
- [[后台续生成]]：负责其余场景的生成与保存；本单元负责目录、未就绪边界和已保存内容的播放。双方为相关单元，不互相设为硬依赖。
- [[课堂讨论]]：负责三名固定 Agent、真实对话、聊天保存与可选文档引用；本单元负责讨论动作出现时的教学提示和播放暂停、继续，不复制讨论逻辑。
- [[配置模型]]：负责设置入口及客户端配置管理；本单元仅在简答批改请求中消费对话配置，不把设置单元尚未实现变成基础播放的硬依赖。
- 治理约束：[[intent]]、[[adr-001]]、[[adr-002]]、[[adr-003]]、[[adr-004]]、[[adr-005]]。本 spec 沿用无登录、PostgreSQL、按请求携带模型配置与确认后定稿的决定，不新增 ADR。
