# 课堂播放与测验

2026-10-25 契约变更：取消 `discussion` 动作的提示与暂停，新增用户展开聊天时的暂停衔接。此前已验证的是旧契约；本版规格待审查，变更待实现与验证，原有 plan、tasks 和历史验收不作为新行为的交付证据。

## 承诺

课堂已由「确认大纲并生成首屏」定稿并保存完整首场。用户点击「进入教室」后进入 `/classroom/[id]`，观看已保存的幻灯片与讲稿、完成测验，并可凭同一课堂 id 再次进入。

课堂目录按定稿大纲展示场景顺序与就绪情况，只允许播放已保存完整内容和讲稿的场景。首次进入从第一场开头自动播放；再次进入恢复上次成功保存的场景，从该场开头自动播放，不恢复上次的暂停状态。保存位置失效时回到首场并提示。草稿或缺少完整首场时提供返回该课生成页的入口；课堂不存在或读取失败时展示错误，读取失败可重试。

幻灯片保留已保存的布局、样式、背景与层次，支持文字、形状、线条、图表和公式，随窗口等比适配。讲稿以字幕显示，按已保存的动作顺序播放，支持开始、暂停、继续、下一段和重播本场。字幕自动推进时须留出可阅读时间；暂停时保留当前画面与字幕，下一段不跳过中间教学动作。本场讲解结束后停留，由用户切换场景，不合成语音。

播放须呈现已有的聚焦、激光、组件高亮、状态提示和标注，效果与对应元素或题目保持一致。播放不再通过 `discussion` 动作展示话题或发起讨论；旧场景中已有的该动作不触发讨论、聊天或强制暂停，其余有效讲稿与动作继续。用户可主动展开由「课堂讨论」提供的右侧聊天窗口，展开时暂停正在进行的讲解并保留画面与字幕，收起后由用户手动继续；真实 Agent 问答及聊天保存由该单元负责。无法展示的内容或无法执行的其他动作须明确提示，不阻塞其余可用内容；切场或重播后，旧场景的教学效果不影响新播放。

用户可以上一场、下一场或从目录选择已就绪场景，切换后从目标场景开头自动播放，并保存当前位置。目标未就绪时保留当前场景，提示并允许重新读取。后续完整场景就绪后可播放，不打断当前讲解或作答，也不自动切场；续生成失败不影响已有内容。仅当全部场景就绪且最后一场讲解结束时，提示已到课程末页，保留回看和返回首页入口，并提示尚未完成批改的测验。到达末页不代表全部作答或已经掌握课程。

测验支持单选、多选和简答，逐题提交并反馈；未提交时不主动展示答案、解析、评分依据或得分。无有效答案时不能提交，允许跳过测验继续观看。单选答案一致得满分；多选须与正确答案完全一致，顺序不影响，错选、漏选或多选均为零分。选择题判分不调用模型。简答按已保存的题目、参考解析与评分依据调用对话模型批改，展示得分、满分、评语与参考解析，得分不得超出该题范围。

测验用于学习练习，每题提交后可以主动重做；简答批改处理中暂不允许改答或重做，批改失败后可重试原答案或重新作答。重做时收起上次的答案与反馈，允许重新填写；新答案成功保存前仍保留上次已保存记录，取消重做可恢复查看。新答案保存成功后替换该题当前答案及批改状态，重新判分，不将上次得分当作本次结果。每题只恢复最近一次成功保存的提交及其批改状态和结果，不提供历史尝试列表。

同一轮重复提交不产生重复记录或重复批改；多个页面基于同一份记录同时提交时，以首先成功保存的答案为准，其他页面须恢复最新记录后才能再次重做。旧答案的批改结果不得覆盖新提交。已提交答案、批改状态、结果和当前场景须持久保存，刷新或再次进入可恢复；重播不清除答题结果。未提交输入在本次页面内切场后仍保留，不承诺刷新后恢复。当前版本无登录，同一课堂 id 对应同一套已保存记录，不按昵称区分学习档案。

答案或位置保存失败时明确提示，保留当前输入或可用内容并允许重试；未保存成功不得显示成功。简答批改未完成或失败时保留已保存答案，允许重试；已有本次提交的批改结果直接恢复，不因刷新或重复提交再次批改，主动重做并提交新答案后才重新判分。读取、播放、切场、回看结果和选择题判分不要求模型或知识库可用；仅简答批改需要当次请求的对话配置，不要求 PDF 检索或向量配置。

## 非目标

- 不生成、编辑或重新排序大纲、场景与讲稿；后续场景生成及其重试由「后台续生成」负责。
- 不实现三名 Agent 对话、聊天保存和文档引用；由「课堂讨论」负责。
- 不提供语音合成、语音识别、音视频同步、视频播放、图片生成、PDF 图片提取、白板、interactive 或 PBL 场景。
- 不提供幻灯片编辑器、缩略图、导入导出、联网搜索、Tool Chat、Plan 蓝图或评审闭环。
- 不提供登录、多人独立成绩册、教师评分管理、防作弊、错题本、历史尝试列表、整课总分或学习统计。
- 不提供模型设置界面或首页历史列表，不承诺精确播放时间与未提交输入的跨刷新恢复。

## 验收

- CP-1 WHEN 首场完整保存后用户点击「进入教室」或凭课堂 id 再次进入，THE SYSTEM SHALL 展示同一课堂的内容与目录，首次从首场开头自动播放，已有有效位置时恢复该场景并从头自动播放。草稿或缺完整首场时提供返回生成页入口；无效课堂或读取失败时展示错误，读取失败可重试。
- CP-2 WHEN 用户观看幻灯片或调整窗口，THE SYSTEM SHALL 保留已保存的布局、样式和层次，正确展示文字、形状、线条、图表与公式，并等比适配。无法显示的部分有明确提示，其余内容仍可观看。
- CP-3 WHEN 用户开始、暂停、继续、进入下一段或重播本场，THE SYSTEM SHALL 按保存顺序播放讲稿与教学动作，字幕有可阅读时间；暂停停止推进，下一段不跳过中间动作，重播从头开始。本场结束后停留，不自动翻页或合成语音。
- CP-4 WHEN 播放教学动作，THE SYSTEM SHALL 展示对应聚焦、激光、组件高亮、状态提示或标注；已有 `discussion` 动作不展示话题、不触发聊天、不据此强制暂停，其余有效动作继续。用户主动展开课堂聊天时暂停正在进行的讲解并保留画面与字幕，收起后由用户手动继续。其他异常动作可提示后继续，切场或重播后旧效果不干扰新播放。
- CP-5 WHEN 用户切换场景，THE SYSTEM SHALL 只进入已就绪场景，从该场开头自动播放并保存位置；目标未就绪时保留当前场景并允许重读。尚有未就绪场景时不宣称整课结束；全部就绪且末场讲解结束时提示到达末页，可回看、返回首页并查看未完成批改的位置。
- CP-6 WHEN 用户提交有效单选或多选答案，THE SYSTEM SHALL 按已保存正确答案判分，完全正确得满分，否则零分，多选顺序不影响；保存成功后展示用户答案、正确答案、得分与解析。未提交时不主动展示答案和解析，判分不调用模型。
- CP-7 WHEN 用户提交有效简答且对话配置可用，THE SYSTEM SHALL 保存答案，按该题评分依据批改并保存结果，展示范围内得分、满分、评语与参考解析；不要求 PDF 或向量配置，缺配置或批改无效时不得显示批改成功。
- CP-8 WHEN 答案、位置或批改结果保存失败，或简答批改失败，THE SYSTEM SHALL 明确区分未保存与已提交待批改，保留相应输入或已存答案并允许重试；已有最终结果直接恢复，不重复批改，批改失败不当作零分。
- CP-9 WHEN 用户重复提交、主动重做或多个页面同时提交同题，THE SYSTEM SHALL 在同一轮提交中只保留首先成功保存的答案，不重复记录或批改；其他页面恢复最新记录后方可再次重做。重做时收起上次答案与反馈，新答案成功保存前保留旧记录，取消可恢复查看；新提交成功后更新该题当前记录并重新判分，不展示旧得分作为新结果。简答批改中不可改答或重做，失败可重试原答案或重做；旧批改不覆盖新提交，不提供历史尝试列表。
- CP-10 WHEN 用户切场后返回、刷新或凭课堂 id 再次进入，THE SYSTEM SHALL 恢复各题最近一次成功保存的答案、批改状态和结果，重播不清除答题记录；本次页面内切场保留未提交输入。刷新后从上次成功保存场景的开头自动播放，不自动重新批改；位置失效时回到首场并提示。
- CP-11 WHEN 模型未配置或知识库不可用，THE SYSTEM SHALL 仍允许读取、播放、切场、回看结果及提交选择题；简答配置错误只影响本次批改，不阻塞其他课堂操作。
- CP-12 WHEN 后续完整场景保存或续生成失败，THE SYSTEM SHALL 在内容更新后反映目录就绪情况，保留当前讲解、答题输入和已存结果，不自动切场；已有场景仍可播放。本单元不承担生成与生成重试。
- CP-13 WHEN 读取场景或提交播放位置与答案，THE SYSTEM SHALL 由服务端校验场景、播放位置、题目及所提交选项均属于当前课堂，拒绝非法读写及客户端自行指定的判分标准与得分；不同课堂的内容和记录不混用。

## 系统不变量

- 场景类型只有 `slide` 与 `quiz`；以本课堂已保存的完整场景为播放内容，定稿大纲提供结构与顺序。
- 播放不改写定稿大纲、场景与讲稿，不以播放位置代替生成进度。
- 判分依据来自该题已保存内容，教学动作不修改用户答案或判分结果。
- PostgreSQL 是课堂内容、播放位置和答题记录的唯一持久化事实来源；IndexedDB 等浏览器存储只能作为界面缓存。
- 每题恢复最近一次成功保存的提交及其批改状态和结果；只有用户主动重做并成功提交新答案，才替换该题当前记录。
- 无登录，持有课堂 id 即可访问该课堂；不承诺不同访问者的独立学习记录。
- 对话配置只来自当次请求，不读服务端环境变量兜底，不保存密钥到课堂或答题记录。

## 非功能约束

- 错误信息须可理解，不包含堆栈或密钥，并有相应恢复入口。
- 主要播放与作答操作可用键盘完成，状态不只靠颜色表达；深浅主题与窄屏下内容和控制入口可读可操作。
- 生成内容只用于受控展示，不执行其中的脚本。
