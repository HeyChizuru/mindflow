# 课堂播放与测验：前端行为适配与联调记录

## 实施范围

课堂播放入口改为消费 `/api/classroom` 的真实课堂、目录、场景、播放位置及答题记录。页面状态由课堂会话统一协调；切场通过既有 PATCH 保存位置，逐题通过既有 `/api/quiz-grade` 提交和读取权威结果。按课堂 id 与场景、题目组成的完整身份隔离记录；使用请求标识与预期版本复用后端幂等和冲突处理。简答只在提交或用户显式重试时使用当次对话配置。

播放接入既有有序引擎与受控教学动作；切换或重播会结束旧场执行，下一段继续处理顺序中的教学动作，讨论提示暂停本场。内容刷新合并已持久化场景和答题记录；输入、当前场景和有效播放状态在页面内保留。播放器不承担后续场景生成或真实 Agent 讨论。

## 验收记录

2026-10-23，使用独立临时 PostgreSQL 课堂和本地浏览器逐项检查，没有接触其他课堂数据。

- **CP-1、CP-2：读取与展示。** 浏览器读取真实 API 响应并展示保存的课程目录、幻灯片、图表与公式；实际检查无效课堂地址、草稿、首场未就绪和首场完整场景。首次进入从首场开播；页面重载和开发服务重启后从数据库记录的场景位置恢复并重新开播。
- **CP-3、CP-4：播放与动作。** 实际操作开始、暂停、继续、下一段和场景切换。下一段依序执行高亮、标注和教学状态，再进入下一段字幕；讨论话题和引导出现时暂停，点击继续后恢复；本场结束后保留当前场景。新场景播放前旧场效果已清理。
- **CP-5、CP-12：位置、内容更新与结束。** 切到测验后从数据库读取到相同 `savedSceneId`。未就绪场景点击后原画面不变并可重读。加入已就绪末场后，刷新目录不改变当前场景与讲解／作答输入；用户选择末场并看完后才出现课程末页，回看和返回首页入口可见。
- **CP-6、CP-9、CP-10：选择题与记录恢复。** 单选和多选经真实 POST 保存、服务端判分，页面显示与 API 读回一致。主动重做隐藏旧反馈，取消恢复旧记录；新答案保存后数据库版本递增，刷新页面恢复新答案和结果。两个页面基于同一版本竞争提交时，先成功保存者生效；旧版本页面出现冲突，在读取最新记录前不显示旧成绩，读取后恢复数据库中的最新答案。
- **CP-7、CP-8、CP-11：简答与失败处理。** 首次简答答案已保存，模型连接因开发服务未使用系统根证书而失败；页面明确显示“已保存、批改失败”，保留原答案并提供重试。用户授权重启服务后，通过 Node 系统证书完成一次显式重试，模型返回有效分数、评语与参考解析，三者经页面和数据库读回核对。没有关闭 TLS 验证、自动重试或替换服务端判分。
- **CP-13：归属与版本。** 浏览器请求携带当前课堂／场景／题目标识；服务端拒绝过期版本写入并返回冲突，由页面要求先恢复最新记录。后端既有归属与答案校验仍是读写依据。

## 检查边界

- 本记录验证实际浏览器与本地 PostgreSQL、既有课堂 API 以及一次真实模型批改；没有模拟每种数据库写入故障、网络中断、超时、旧批改覆盖新提交、所有浏览器／屏幕尺寸组合或真实后台续生成。后续生成与 Agent 对话仍属于其他功能单元。
- 首次模型请求遇到本机证书链问题；使用系统证书后成功。该修复仅作用于经授权启动的本轮开发进程，没有关闭 TLS 校验，也没有改写仓库配置。
- 本记录撰写时遵从 spec frontmatter；当时没有把草案 spec 标记为已接受或把功能状态改为 verified。按项目约定未运行 `pnpm build`，未新增测试文件。
- 验收使用的临时课堂、场景、位置与答题记录在本轮结束前删除。
