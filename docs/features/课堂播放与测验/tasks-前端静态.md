## 目标与边界

复用现有课堂播放骨架，交付可审阅、可演示的目录、幻灯片、字幕、控制栏、教学效果、三类测验及异常状态。静态展示使用与后端契约一致的样例，为阶段五接入真实行为提供共用组件。

- 静态预览只使用本地样例、页面内状态和操作回调，不发送课堂、位置、答题、模型或生成请求，不读写真实课堂记录。
- 样例成绩与保存状态须在预览入口明确标为演示；不根据用户输入执行正式判分，不用计时器或动画冒充请求完成。
- 正式课堂与预览共用展示组件，演示控制只存在于开发预览。保留已有正式页面读取和播放适配代码，不将正式课堂替换成样例，不向正式页面加入模拟成功行为。
- 本阶段可完成输入、选项切换、目录展开、状态切换和取消重做等本地演示；真实请求、自动开播、字幕计时、动作顺序、保存及恢复、并发处理、跨场景输入保留和内容更新留阶段五。
- 新依赖须先列出包名、用途并取得用户确认；安装权限不代替依赖选型确认。
- 沿用现有 shadcn 组件、主题语义色、[品牌规范](../../brand.md) 和 Logo 资产。只调整本模块涉及的样式，不进行全站换肤或组件库迁移；幻灯片自身沿用已保存的内容颜色和样式，不被界面主题重着色。

## 当前基础与缺口

2026-10-22 只读核对：

- 后端 B1～B7 已交付。`lib/types/classroom.ts` 提供 `draft / first_scene_pending / ready` 读取分支、定稿目录、就绪状态、恢复位置和当前答题记录；`pending / processing / failed / completed` 以及 `executionExpired` 已能表达批改状态。错误响应另有 `answerSaved / submissionId / record`，不能只凭 HTTP 成败决定页面是否已保存。
- `app/classroom/[id]/page.tsx` 仍使用清理阶段的临时解析器，未消费新读取分支、位置和答题记录。本阶段提取展示边界；正式响应解析与接入留阶段五，不继续扩充临时协议。
- 当前主链为 `Stage → PlaybackChromeRoot → SceneSidebar / CanvasArea → SceneRenderer → SlideEditor / QuizView`。`PlaybackChromeRoot` 混合引擎与展示，目录直接读取 store，`SceneProvider` 也从 store 获取场景，预览需要解除这些展示依赖。
- 目录按已有 `scenes` 展示，以 `generatingOutlines` 和 `PENDING_SCENE_ID` 表示等待／结束；不能直接表达完整定稿目录，现有课程完成判断也未包含末场讲解结束。工具栏缺少下一段和独立重播入口，全屏时字幕与讨论提示被隐藏。
- `ScreenElement` 已保留文字、形状、线条、图表、公式组件，但部分格式仍走不可显示提示；图表及共享工具引用 ECharts、tinycolor2，`package.json` 尚未声明。文字、形状文字与公式存在直接 HTML 注入，公式样式和受控展示仍需核对。
- `QuizView` 已有三类输入和反馈结构，当前仍是测验封面、顶部统一禁用提交及组件内输入；逐题状态、重做／取消与错误恢复尚未展示。三类 widget 动作在 `ActionEngine` 中仍返回未接入，本阶段准备视觉落点，不改其执行规则。

## 文件范围与实现思路

以下为仓库相对路径。共用类型和子组件仅覆盖本模块；不为静态预览新增通用状态框架。复用项不要求全部产生 diff。

### 新增

- `components/stage/classroom-view.tsx`：接收目录、当前场景、播放与答题展示状态及操作回调，组合共用课堂外壳；不创建引擎、请求数据或保存记录。
- `components/stage/classroom-status.tsx`：加载、不可播放、读取错误、恢复提示、场末／课程末页及保存提示的共用展示，不自行读取或重试接口。
- `components/stage/playback-caption.tsx`：字幕、讨论话题／引导和继续入口，供普通与全屏布局共用。
- `components/stage/teaching-feedback.tsx`：元素／题目关联的标注和状态提示展示，复用现有聚焦、激光及高亮组件；不修改题目、输入或成绩。
- `components/stage/classroom-view-types.ts`：上述组件的展示状态和回调类型。复用 `Scene`、`Action`、`ClassroomDirectoryEntry`、`QuizSubmission` 等现有领域类型，区分服务端记录与本地输入／重做／提交中状态，不另造接口协议。
- `lib/utils/sanitize-slide-html.ts`：文字、形状文字与公式共用的受控 HTML 展示入口；采用适合浏览器的成熟净化库，按需要保留文本样式、公式结构并限制标签、属性和 URL，不自行用正则拼凑安全过滤。
- `app/classroom/static-preview/page.tsx`、`app/classroom/static-preview/fixtures.ts`：开发预览与本地样例；页面内选择状态、场景、教学效果和题目记录，不创建真实课堂。生产环境不提供此预览入口，正式产品不增加第四个业务页面。

### 修改与复用

- `components/edit/PlaybackChromeRoot.tsx`：保留现有引擎／store 适配，提取展示到 `ClassroomView`；不在本阶段补真实自动播放、下一段算法、位置保存或答题请求。新增但尚未接通的正式操作保持不可用并说明原因，不用预览回调冒充真实实现。
- `components/stage/scene-sidebar.tsx`：以传入的定稿目录、当前场景与回调展示列表；不再由展示组件自行从 `scenes` 推断全部目录或改变 store。
- `components/header.tsx`、`components/canvas/canvas-area.tsx`、`canvas-toolbar.tsx`：复用标题、画布和控制栏，补明确的上一场／下一场可用状态、下一段、重播、全屏字幕及窄屏布局；不再只凭已加载场景数量决定导航展示。
- `components/stage/scene-renderer.tsx`、`lib/contexts/scene-context.tsx`：支持显式传入只读场景和测验展示参数。`SceneProvider` 保留正式 store 适配方式，并支持预览传入场景，避免写入正式 stage store 才能查看样例。
- `components/slide-renderer/Editor/{ScreenCanvas,ScreenElement,SpotlightOverlay,LaserOverlay,HighlightOverlay}.tsx`、`hooks/useViewportSize.ts`：补静态效果输入和布局适配，统一缩放与定位依据；继续复用既有 hook，不另建一份视口实现。
- `components/slide-renderer/components/element/` 下的 `TextElement/BaseTextElement.tsx`、`ShapeElement/BaseShapeElement.tsx`、`LineElement/BaseLineElement.tsx`、`ChartElement/{BaseChartElement,Chart,chartOption}.tsx`、`LatexElement/BaseLatexElement.tsx`：按本项目字段适配五类必需元素、受控 HTML 和必要容错；不引入编辑包装或增加表格／代码块验收范围。
- `components/scene-renderers/quiz-view.tsx`：复用题目卡片、三类输入和反馈，改为逐题展示状态与回调；输入、已保存记录及重做草稿分别表达，不在组件内判分或持久化。
- `lib/utils/geometry.ts`、`lib/utils/element.ts`、`lib/store/canvas.ts`：仅在现有定位或效果展示确有需要时适配；页面内效果仍是临时状态，不扩展为课堂或成绩事实来源。
- `lib/hooks/use-i18n.ts`、`app/globals.css`：补本模块文案、公式样式和必要展示样式；复用已有语义 token，不重写全局主题。已有 `components/ui/` 优先复用，确需补基础控件时仅添加本阶段实际使用的组件并记录文件。
- `package.json`、`pnpm-lock.yaml`：补齐当前渲染链需要的 ECharts、tinycolor2、必要类型声明及 HTML 净化依赖；实施时核对官方 API 和实际导入，不为退出播放链的 shiki、Dexie 等旧源码安装依赖。
- 本 task 与 `docs/index.md`：提供入口，实施后回填实际文件、检查结果与未覆盖项。

`app/classroom/[id]/page.tsx`、`components/stage.tsx` 和现有领域类型作为接入参照，不预设修改。`lib/playback/*`、`lib/action/engine.ts`、stage store 的业务状态、API、服务、数据库、生成页、reference、spec／plan 和 AGENTS.md 不在本阶段实现改动范围内。

- [x] 补齐最小渲染依赖，核对本项目元素字段与现有 Base 组件的差异；有效形状、线条和图表不能仅因可适配的格式差异长期显示占位，也不通过修改服务端契约迁就原项目类型。

- [x] 修正画布容器与既有视口缩放配合，按保存的 `viewportSize / viewportRatio` 等比适配；核对非 16:9 幻灯片，避免外层固定比例导致裁切或变形。测验阅读区不强制压进幻灯片比例。
- [x] 文字、形状文字与公式统一经过受控 HTML 展示；验证事件属性、危险 URL 和可执行内容被阻止，保留必要排版和公式样式，不把含危险属性的内容直接传入 `dangerouslySetInnerHTML`。
- [x] 图片／视频和其他非本阶段承诺的元素保留清晰降级提示，不扩展图片生成、视频播放、表格、代码块或编辑器。

映射：CP-2 及生成内容受控展示约束；实际保存内容的完整联调留阶段五。

### F4 — 补齐字幕、控制栏与教学效果展示

- [x] 控制栏提供开始／暂停／继续、下一段、重播本场、上一场／下一场及现有全屏入口；可用性由展示状态与回调决定。明确区分下一段与下一场，不用切场按钮替代讲稿推进。
- [x] 准备播放中、暂停、讨论等待继续和本场结束状态；字幕支持长文本阅读，暂停样例保留当前字幕与画面。普通与全屏都能看到字幕、讨论话题／引导及继续入口。
- [x] 复用聚焦、激光、高亮覆盖层，补元素／题目关联的标注和状态提示；在缩放、旋转元素、滚动题目与窄屏中检查定位及可读性，不遮挡作答操作。
- [x] 效果只读取已有动作／状态，标注按文本展示，状态提示不写入题目答案或成绩；不执行任意 state、脚本或 iframe 消息。样例只使用含义明确的数据，无法解释的目标／状态有可见提示，不发明新的教学规则。
- [x] 开发预览通过手动切换演示效果与错误提示，并在更换样例时复位预览效果；真实动作消费、计时、暂停保留、切场／重播清理及旧回调隔离留阶段五，不据静态复位认定引擎已正确清理。

映射：CP-3、4 的操作入口和视觉状态，以及 CP-5、10 的展示边界。

### F5 — 改造逐题测验与反馈状态

- [x] 单选、多选、简答分别提供输入和逐题提交入口；单选支持键盘选择，多选可逐项切换，简答有明确标签。未选有效答案或仅有空白文本时禁用提交，允许跳过测验继续观看，不要求整组作答后统一提交。
- [x] 未提交时不主动展示正确答案、解析、评分依据或得分。完成样例从传入的本次记录读取用户答案、得分／满分、解析，以及选择题正确答案或简答评语；不再以浏览器比较产生正式成绩。
- [x] 区分本地提交中、答案未保存、保存结果不确定，以及已保存的 `pending / processing / failed / completed`。未完成状态不显示旧得分或用零分填充；已保存答案与未保存输入的提示和恢复入口不同。
- [x] 缺模型配置、模型／结果保存失败和执行过期有对应提示及恢复入口。未过期处理中禁止改答、重做和重复批改；待批改、失败或过期样例展示显式重试原答案及按契约允许的重做入口，不自动发起批改，不在前端另设 120 秒执行期限或据本地倒计时宣称已落库失败。
- [x] 重做样例收起旧答案与反馈，单独保留旧记录和新输入；取消恢复旧记录，新提交完成样例才展示新结果。重播本场不作为清除答题记录的入口。
- [x] 准备版本冲突提示和恢复最新记录入口；通过样例区分本次答案未保存与其他页面已有记录，不把胜出页面的记录称为本次提交成功。保存结果不确定时提供先读取确认的入口，不直接提示重新批改。
- [x] 题目与记录以课堂／场景／题目身份关联，不只按 questionId 全局复用；演示已有结果、未提交输入与重做状态，实际跨场景保留、刷新恢复、版本与请求标识管理留阶段五。

映射：CP-6～11 的输入、反馈和恢复状态；CP-13 的服务端归属校验不由本阶段静态样例代替。
