## 承诺

### 列表范围与入口

首页保留现有建课入口，在建课区域下方增加「历史课堂」。列表以服务端已持久化的课堂为事实来源，包含本功能上线前已经创建的课堂，以及草稿、已定稿但首场未完成、部分场景就绪和全部场景就绪的课堂。没有 PDF 或没有配置模型不影响列出已有课堂。

默认按创建时间从新到旧排列，同一创建时间采用稳定顺序。全部课堂都应可到达；若分批展示，必须提供继续查看的入口，不能只显示固定数量后使其余课堂无法访问。分批展示路线见 plan，具体批次参数在对应阶段展开。

用户打开或返回首页时，读取服务端当前记录。加载中、读取失败、没有任何课堂和搜索无结果须分别表达；读取失败可重试，不伪装成空列表。历史区域的加载或失败不阻塞既有建课输入与提交。

### 卡片信息与视觉

每张卡片提供内容预览、当前课堂标题、页数或就绪进度、时间、可理解的阶段提示，以及重命名和删除入口。桌面使用卡片网格，窄屏减少列数并允许正常滚动；卡片不能挤压到不可读，也不能遮住首页的建课入口。

信息口径如下：

- **预览**：使用定稿顺序中第一个场景已完整保存的可展示内容。首场为幻灯片时展示其静态缩略内容；首场为测验时只展示测验类型、标题或题干，不展示正确答案、参考解析、用户答案或成绩。不执行讲解动作或播放。尚无完整首场时展示带课堂阶段的统一占位，不调用模型补封面。
- **页数**：一份定稿大纲中的一个场景计为一页，包含幻灯片和测验。全部就绪显示「N 页」；部分就绪显示「已生成 M / N 页」；大纲未确认时显示「未定稿」，不把未确认大纲或尚未保存的内容计入页数。页面内尚未保存的进度不作为历史列表事实。
- **时间**：使用课堂创建时间，明确为「创建于」或「…前创建」。不把数据库更新时间当成最近学习时间；本单元不新增最近访问或学习时长统计。
- **阶段**：区分未定稿、首场未就绪、部分就绪和全部就绪。生成失败的课堂仍可列出，但没有持久化的失败或执行依据时，不凭空还原上次失败提示，也不把离页前的临时状态显示为仍在生成。

参考图只作为布局参考。配色、品牌和深浅主题沿用 MindFlow 的既有视觉规范；不因此引入截图里的导入导出等未确认能力。

### 再次进入与恢复

点击卡片后，以该课堂当前服务端保存结果决定落点：

- 大纲尚未确认：进入 `/generation-preview/[id]`，恢复已保存的需求与资料。依据 ADR-005，确认前的流式大纲、手改结果与授课语言指令不因新增历史入口而变为可恢复数据。
- 大纲已确认，但定稿顺序中的首场尚未完整保存：进入生成预览，读取已保存定稿，并沿用首场生成与失败重试流程；不重新生成或改写大纲。
- 定稿首场已经完整保存：进入 `/classroom/[id]`，即使其余场景尚未生成也可进入。按「课堂播放与测验」恢复最近成功保存的场景、作答与批改结果，按「课堂讨论」恢复会话；后续生成沿用「后台续生成」的条件和恢复规则。

不得单凭旧卡片上的阶段或浏览器缓存强行进入错误状态。点击时课堂已被其他页面删除，或当前数据无法读取、校验失败时，应明确提示并允许重新读取；不得创建替代课堂，不把读取失败当成首场未生成。

历史区域的读取、搜索、折叠、重命名和删除不要求模型配置，也不调用生成、入库、批改或问答模型。进入目标页面后是否发起生成，仍由对应功能规格决定。

### 搜索与折叠

按课堂当前标题做包含匹配，忽略输入首尾空白与英文大小写。搜索范围是当前部署下的全部未删除课堂，不局限于当前已加载的卡片。空关键词恢复全部列表；无匹配结果展示明确提示并允许清空。搜索不修改课堂数据，较早请求的晚到结果不得覆盖较新的关键词结果。

区域标题显示全部课堂总数；搜索时另显示匹配数量，不能把当前批次条数当成全部数量。进入首页默认收起，保留区域标题、数量与展开入口，由用户主动展开查看。折叠只隐藏历史区域内容，不删除记录、不取消课堂已保存进度，也不影响建课；本单元不承诺折叠和搜索条件跨刷新保存。

### 重命名

用户从卡片操作入口编辑名称，可确认保存或取消；操作入口不得同时触发进入课堂。

名称去掉首尾空白后为 1～100 个字符，允许重名，不接受纯空白。取消或校验不通过不写入。保存期间防止重复提交；服务端确认成功后更新卡片，刷新与再次进入课堂仍读到新名称。失败时保留输入并允许重试，结果不明时先读回核对，不宣称保存成功。

重命名只改变课堂名称，不改变课堂 id、原始需求、昵称与背景、定稿大纲、场景标题与内容、播放位置、测验或聊天记录，不调用模型重生成内容。新标题参与后续搜索；若不再匹配当前关键词，保存成功后该卡片退出当前搜索结果，并明确反馈保存成功。

### 删除

采用**二次确认后永久删除整节课堂**，不提供回收站或撤销。草稿和已生成课堂均可发起删除。

确认界面须显示目标课堂名称，并说明删除范围：课堂需求与学习者信息、定稿大纲、所有场景与讲稿、播放位置、测验提交与批改结果、所属聊天会话与消息及其引用和执行记录、PDF 原件及其元数据、知识库分块与向量、入库执行记录。取消不修改数据。删除不影响其他课堂，也不清除浏览器中的全局模型配置、个人资料或首页建课草稿。

确认并由服务端核实删除后，移除卡片并更新数量和搜索结果；不误触课堂跳转。数据库记录删除与 PDF 文件清理的结果须如实表达：文件清理尚未完成时，不能把全部数据清理展示为完成，也不能假装课堂记录仍然存在。失败或响应丢失时先读回核对课堂是否存在，再提供相应重试或清理反馈；不得凭客户端移除卡片声称删除成功。

删除与在途入库、场景生成、问答、批改、播放位置保存及旧列表读取须保持一致：成功删除后，旧请求不得重建课堂、关联记录或 PDF 文件，也不得把已删除卡片恢复到列表或污染其他课堂。此要求约束保存结果，不承诺外部模型请求立即终止；其他页面再次操作已删除课堂时应提示已不存在。

### 部署与访问边界

沿用当前无登录、共享部署的形态。历史列表展示部署下的全部课堂，名称、预览及管理操作均不按创建者隔离；不把当前浏览器或昵称作为所有权证明。本单元不引入账号、个人历史或角色权限，对外暴露仍受 ADR-001 的安全与鉴权约束。

## 非目标

- 不新增独立历史页、登录、个人隔离、收藏、分组、学习统计或访问轨迹。
- 不增加课堂导入导出、复制课堂、批量删除、幻灯片编辑或模型生成封面。
- 不新增确认前大纲的持久化，不恢复尚未保存的模型输出、精确播放时间或未提交答案。
- 不改变定稿、首场生成、后台续生成、播放、测验和聊天各自的既有契约。
- 本 spec 不定义接口路径与字段、数据库变更、具体组件或实现步骤；路线由 plan 定义，具体施工内容在进入相应阶段且用户要求时再写 task。

## 验收

- HC-1 WHEN 用户打开或返回首页，THE SYSTEM SHALL 从服务端读取当前部署下的全部未删除课堂，包含旧课堂、未定稿、首场未就绪、部分就绪与全部就绪课堂；不同浏览器可读到同一部署的数据，不依赖本浏览器创建记录。分批展示时其余记录仍可到达。
- HC-2 WHEN 历史区域展示课堂卡片，THE SYSTEM SHALL 按本稿约定展示标题、首场静态预览或占位、真实页数或就绪进度、创建时间与阶段，并按创建时间从新到旧稳定排序；不得泄露测验答案或冒充最近学习时间，预览不触发模型调用或动作播放。
- HC-3 WHEN 用户点击未定稿或定稿后缺完整首场的课堂，THE SYSTEM SHALL 进入该课堂生成预览，按已保存状态分别恢复需求与资料或已确认大纲及首场恢复流程；不承诺恢复确认前大纲，不新建课堂或重新生成已确认大纲。
- HC-4 WHEN 用户点击首场已完整保存的课堂，THE SYSTEM SHALL 进入同一课堂播放页，即使后续场景未全部生成；依既有规格恢复已保存的播放、测验和聊天状态，且不重生成已有完整场景。没有模型配置不阻塞已有内容的读取与播放。
- HC-5 WHEN 用户输入、修改或清空搜索词，THE SYSTEM SHALL 按当前标题在全部课堂中执行忽略首尾空白与英文大小写的包含匹配，空词恢复全部；显示真实匹配数，区分无结果与读取失败，旧响应不覆盖当前搜索。
- HC-6 WHEN 用户进入首页，THE SYSTEM SHALL 默认收起历史区域并保留标题、数量和展开入口；用户主动展开或再次收起时恢复或隐藏卡片区，不改变已保存数据或影响建课；重命名、删除入口不同时触发进入课堂。
- HC-7 WHEN 用户保存合法新名称，THE SYSTEM SHALL 校验名称并持久化，服务端确认后更新展示，刷新与再次进入可读回，搜索使用新名称；不改变课堂身份、需求、定稿、场景和学习记录。取消、空白或超长名称不写入，失败或结果不明时可保留输入并核对重试。
- HC-8 WHEN 用户发起删除并取消二次确认，THE SYSTEM SHALL 保留课堂及全部关联数据；确认界面明确显示目标与永久删除范围，不因点击删除入口直接执行删除。
- HC-9 WHEN 用户确认删除且服务端完成删除，THE SYSTEM SHALL 按本稿约定清理该课堂及关联数据和 PDF 原件，移除卡片并更新数量；其他课堂和全局浏览器设置不变，旧课堂链接不可再恢复该课堂。不把部分清理或未知结果展示为全部完成。
- HC-10 WHEN 删除与入库、生成、问答、批改、位置保存或旧读取并发，THE SYSTEM SHALL 在删除成功后拒绝对已删除课堂的晚到保存，不重建记录或文件，不恢复卡片，不影响其他课堂；不得只依赖浏览器取消请求满足此项。
- HC-11 WHEN 列表加载、读取失败、课堂为空、搜索无匹配，或点击与管理操作遇到课堂已删除、数据异常、保存失败或结果不明，THE SYSTEM SHALL 分别展示可理解的状态及适用的重读、重试或清理入口；不误报成功、不把失败当空数据，不阻塞首页建课。
- HC-12 WHEN 使用深浅主题、窄屏或键盘操作，THE SYSTEM SHALL 保证历史区域、卡片、搜索、折叠及管理弹窗可读可操作；历史内容可滚动到达，不遮挡建课，管理操作有独立可识别入口和焦点反馈。

## 系统不变量与非功能约束

- PostgreSQL 与已保存 PDF 是相应数据的事实来源；浏览器仅作界面缓存，不能决定课堂是否存在、页数或删除结果。
- 列表、搜索、重命名与删除不调用模型，不读取或暴露 API Key、PDF 全文、数据库内部路径或错误堆栈。
- 列表摘要和预览只提供展示所需信息；不以把所有课堂的完整场景、测验答案、聊天和 PDF 下载到首页作为列表契约。
- 所有操作始终以课堂 id 定位；允许重名也不得误操作其他课堂。
- 生成内容按既有受控展示规则渲染，不执行其中脚本；阶段不能仅用颜色表达，管理弹窗关闭后恢复合理焦点。

## 已确认决策

以下五项建议已获用户于 2026-10-30 确认，作为后续实施与验收依据；其中折叠默认值按用户后续「默认收起」的指令更新。

1. **排序与时间**：按创建时间倒序，卡片显示创建时间，不新增最近学习时间。
2. **预览与页数**：以完整首场作预览；测验不展示答案；页数按定稿场景计，未生成完成显示「M / N」，未定稿显示占位。
3. **搜索与折叠**：仅按标题做包含匹配；进入首页默认收起，搜索词和折叠状态不要求跨刷新保存。
4. **名称规则**：去首尾空白后 1～100 字符，允许重名，只改课堂名称。
5. **删除语义与共享管理**：二次确认后永久删除整课及上述关联数据和 PDF，无回收站；当前无登录部署下，能访问首页的使用者均可对列出的全部课堂重命名或删除。

- 硬能力依赖：[[创建课堂]]、[[确认大纲并生成首屏]]、[[课堂播放与测验]]，分别提供持久化课堂、定稿与首场事实、再次进入的播放和恢复契约。

- 相关：[[文档入库]]、[[后台续生成]]、[[课堂讨论]]、[[配置模型]]；删除涉及前三者的数据与在途写入，读取和管理不依赖模型配置。
- 「创建课堂」旧 plan / tasks 移除开源历史入口的记录保留为历史交付范围；本单元定义新的服务端历史入口，不恢复以浏览器存储作为课堂事实来源的旧链路。
