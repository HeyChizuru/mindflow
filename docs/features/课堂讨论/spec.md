## 承诺

课堂已定稿并保存完整首场，用户在 `/classroom/[id]` 观看已就绪场景时，可主动展开右侧聊天窗口，围绕本课程与当前场景提问、追问或表达自己的理解。课堂不再通过 `discussion` 教学动作提出话题或发起对话；新场景不生成该动作，旧场景中已有的该动作不触发讨论、聊天或强制暂停，其他有效讲稿与动作仍可播放。

聊天窗口由用户主动展开和收起。展开时暂停正在进行的讲解，保留当前画面与字幕；收起后保持暂停，由用户手动继续。展开、收起或读取聊天记录不自动发送问题、不调用教师生成回复，也不重播当前场景。后台续生成仍按其独立流程运行。

### 会话创建、选择与删除

用户可新建独立聊天会话。新会话固定关联创建时正在显示的课堂；同一课堂可以建立多个会话，切换课堂后也可基于新显示的课堂创建另一个会话。关联固定的是课堂身份，课程事实仍从该课堂已保存且允许访问的数据读取，不把创建时的页面对象作为权威或冻结为资料快照。新会话不继承其他会话的聊天历史或摘要。

会话列表可辨认会话及其所属课堂，支持选择其他课堂的已有会话，不限于当前课堂。打开属于课堂 A 的会话时，若当前显示课堂 B，应同时切回课堂 A；当前画面、活动会话和后续问题的课堂依据须一致。不能在课堂切换尚未成功时把 B 的场景用于 A 的会话，也不能把打开会话当作重新发送问题或重新生成回复。会话关联课堂不会随用户之后浏览其他课堂而改变。

刷新后保持当前会话选择；普通进入课堂、没有明确会话选择时，恢复该课堂最近使用的未删除会话，不默认选中其他课堂会话。该课堂没有会话时显示空态，由用户主动新建，不自动创建空会话。明确未选择会话的状态也应在刷新后保持，不能因此自动选中其他会话；读取失败不当作“没有会话”。

删除会话须由用户二次确认，取消不改变已保存数据。确认并成功删除后，永久删除该会话及其聊天记录（含完整回复、教师身份、引用关联和执行记录），不删除所属课堂、场景、PDF 资料、正式测验答案或成绩。第一版不提供回收站或撤销删除。删除失败或结果不明时明确反馈，不把未确认的删除展示为已完成。

删除当前会话成功后保留当前课堂画面，聊天区回到未选择会话的空态，不自动新建、不自动切到其他课堂或会话；删除非当前会话不改变当前聊天。

会话删除与在途问答、读取和重试之间须保持一致：删除成功后，晚到的生成结果、保存回调、重复提交或旧读取不得重建该会话、恢复其消息或写入其他会话。该约束由服务端持久化归属与写入校验保障，不能仅依赖浏览器取消请求；不因此承诺外部模型调用一定立即停止。

旧版每课堂一份聊天历史按课堂归入一个“历史会话”，保留原问题、完整回复、教师身份、所属场景、引用和执行状态，不重新生成答案、不跨课堂合并。原本没有聊天记录的课堂不因迁移自动创建空会话；迁移和读取不自动继续未完成执行。

### 三名固定教师与自动路由

用户面对同一课堂中的教学团队发问，不需要先手动选择教师。三名教师的职责固定，不自动生成人设：

- **讲解老师**：解释概念、拆解当前内容、补充必要的前置知识，帮助用户听懂。适合“是什么”“为什么”“这句话是什么意思”。
- **思考教练**：分析用户表达的理解与推理，指出具体混淆或遗漏，通过适量追问帮助用户理清思路。适合“我这样理解对吗”“我的思路哪里有问题”。直接提问应得到回答，不以连续反问代替答疑。
- **应用教练**：把课程知识连接到案例、练习或实际项目，分析用户的应用尝试。适合“实际怎么用”“给我一个例子”“让我练一下”。聊天内的练习不成为正式测验，不产生或修改正式成绩。

系统通过 LangGraph 编排，每轮根据用户问题、发送时的课程与场景、相关对话判断由哪位教师回答；不能仅凭孤立关键词忽略前文。本轮由一位教师主导并输出回复，界面标明其身份。用户后续问题的学习需求变化时，下一轮可以选择另一位教师。首版不包含同轮多教师发言、教师间主动交接或任务委派，也不要求三名教师轮流出现。

### 场景上下文、工具与资料

每条问题绑定所属会话，并以发送时该会话关联课堂内正在显示的场景作为本轮上下文，界面可辨认该场景。发送后切换场景，不改变这条问题及其回复的场景依据；同一会话的下一条问题使用发送时的新场景。同一会话保留连续的聊天历史，教师应结合前文理解“它”“刚才那个”等指代；无法明确时提出具体澄清问题，不编造用户所指。切换会话不合并历史，不能因两会话属于同一课堂而共享聊天记忆。

教师可以按需使用只读工具，取得本课当前场景、其他已保存内容或本课 PDF 的相关片段。工具使用由问题需要决定，不要求每轮调用全部工具。读取与检索由服务端校验课堂归属，教师不能通过工具修改大纲、场景、播放位置、用户答案或测验结果。尚未生成的内容不能当作已保存场景引用。

无知识库时，教师仍可基于课程需求、定稿大纲、已保存场景与相关对话回答，不要求向量配置，也不伪造文档引用。有知识库且问题需要资料依据时，教师可结合上下文形成检索问题、读取相关片段；信息不足时可以调整查询后补查。检索与工具调用必须有执行边界，不能无限查找。已有知识库不意味着所有问题都必须检索。

使用 PDF 片段支撑回答时，展示与本条回复关联的真实来源，至少能辨认来源文档、可用页码与相关片段；不能把检索命中直接当作结论正确的证明。没有相关依据时说明资料不足，区分课程资料内容与一般性解释，不编造引用、不把文档全文送入提示词。检索服务失败与“未找到相关资料”须明确区分，失败不得被伪装成检索成功或无相关结果。

### 会话记忆与测验边界

教师仅共享当前会话必要的上下文，包括已经解释的内容、用户明确表达的困惑、使用过的例子和未解决的问题。相关历史选择与本轮临时摘要均限于当前会话；同课堂其他会话及其他课堂会话的聊天记录不得成为本轮记忆。课程内容、PDF 与已保存测验状态仍按课堂及提交状态安全读取，不因会话独立而另建正式测验记录。对话较长时可以整理摘要，为本轮选择相关历史；摘要不能替代原始聊天记录，也不能把模型对用户能力的猜测当成事实。用户说“还是没懂”时，应结合之前的讲法调整解释，不机械重复。未填写昵称或背景时不编造学习者信息。

测验尚未提交时，教师可解释相关知识、提供提示或分析用户思路，不直接提供该题标准答案、完整解析或隐藏评分依据；即使用户直接索要，也保持这一边界。该边界同时适用于上下文准备、历史选择、其他场景读取和资料检索，不能把隐藏答案作为可随意取用的工具结果。提交后可讨论已保存的答案与可用反馈；批改尚未完成时不虚构分数、批改成功或正式评语。主动重做不清除已经保存的聊天，也不承诺让用户忘记此前看过的答案；新一轮作答仍按播放与测验的重做规则处理。

### 流式回复与逐字呈现

用户发送问题后，普通问答在必要的上下文准备、教师选择和按需资料查询之后，随教师生成持续传输最终回答的正文增量。界面以 GPT 式打字机效果连续逐字呈现，不以整段完成作为显示门槛，也不在普通路径等待完整答案后才播放打字动画。此处普通问答指未触发下述完整测验保护检查的轮次；不承诺固定首字耗时或生成速度。

前端平滑呈现收到的正文，网络一次到达多个字时仍保持连续输出，显示积压时可适度加快，避免无必要地拖延已收到内容。中文、emoji、换行与 Markdown 应正确显示，生成中有明确标识及末尾光标。用户停留消息底部时跟随新内容，向上查看历史时不强制拉回；读取已有完整回复直接展示，不重新播放打字动画或调用模型。逐字效果仍须遵守键盘、窄屏、深浅主题和减少动态效果的可访问性要求。

界面依据服务端真实执行反馈展示上下文准备、教师选择、资料查询等当前阶段，教师身份在路由确认后显示，不推测教师或伪造进度百分比。仅最终回答正文作为逐字内容；内部提示词、模型推理、路由及摘要决策、工具参数和原始结构化包装不作为聊天正文展示。

本轮触发测验保护检查时，包括需要核对未提交题提示边界或待批改状态的情况，服务端先取得完整回答并通过适用校验，再允许正文发送到浏览器并逐字呈现；检查失败不外发被拒绝的正文。等待期间仍可显示真实执行阶段，因此首字可以晚于普通问答。本轮保护检查的适用性必须在正文外发前由服务端核对，不能只由前端根据当前场景或用户问题关键词决定，也不能用展示后撤回来代替检查。

普通问答提前显示的正文属于本轮临时预览，不表示引用已验证、回复已完成或已保存。界面区分生成中、校验或保存中、失败或结果待确认、已保存；生成结束与逐字动画结束均不能作为保存成功的依据。完整回复及引用仍经服务端校验和持久化确认，最终以已保存记录收尾。

### 保存、失败与恢复

会话、已保存的用户问题、教师完整回复、教师身份、问题所属场景与回复引用持久保存在 PostgreSQL；每轮记录归属明确的会话及其关联课堂。除用户明确删除外，收起聊天、切场或切换会话不清除已保存记录；刷新或再次进入后，可读取会话列表并打开未删除会话，恢复其完整历史。读取列表和历史不要求模型或向量服务可用，也不自动重新生成已有回复。当前版本仍无登录，会话隔离是聊天上下文与记录归属的隔离，不是用户权限或私有学习档案；不按昵称、浏览器缓存或本地设备推断会话所有者。

问题保存失败时保留输入，明确提示未保存并允许重试；已保存问题的路由、工具调用、检索或回复生成失败时，保留问题与既有聊天，说明本轮未完成并允许重试。完整回复未成功保存时，不标为已保存或可恢复；部分输出不当作完整回复。重复点击、重试或响应丢失后的恢复不应为同一轮重复追加问题或已完成回复；结果不明时先核对已保存结果，已完成则直接恢复。

本单元承诺恢复未删除会话中的已保存聊天，不承诺恢复未发送输入、未保存输出或模型执行到一半的位置，也不承诺离开页面后继续完成问答。收起窗口不清空记录；无论请求是否已经结束，晚到结果都只能归属原会话、原课堂、原问题和原场景，不能更新其他会话或变成新问题的回复。会话已删除时不得写回或恢复。刷新恢复后不因旧请求未完成而自动启动新一轮模型调用。

流传输中断、结束通知丢失或回复保存结果不明时，先按原会话与问题身份读取核对，不因流关闭、已经显示部分正文或光标停止就判断成功，也不自动启动第二轮模型生成。已完成则恢复完整记录；未完成则沿用显式恢复与重试规则。正文增量、执行反馈、晚到结束通知和待显示文字均须绑定原会话、问题及本次执行；切换会话、删除或重试后不得串入其他回复，旧执行的显示队列不得拼到新执行。刷新不恢复未保存正文，也不重放旧流。

对话与向量配置分别来自当次请求，不读取服务端环境变量兜底，不把密钥存入聊天、课堂、会话摘要或执行记录。只有实际需要检索时才要求可用向量配置；缺配置或检索失败时明确提示本次资料查询未完成，不悄悄降级为声称有资料支持的回答。对话模型不能完成路由、工具调用或生成时，应提示本轮失败，不伪装成功。配置、聊天读取或问答失败不阻塞课堂已有内容的观看、切场和其他可用操作。

## 非目标

- 不生成或执行 `discussion` 教学动作，不主动弹出讨论、不在无人提问时自主发言。
- 不提供手动选教师、同轮多教师发言、教师间 Handoff / Delegation、并行辩论或独立评审 Agent。
- 不提供正式测验出题与判分、聊天练习成绩、学习统计、掌握度结论或跨课程长期学习档案。
- 不修改已定稿课程、场景、讲稿与用户答案，不通过教师回复或工具调用驱动播放动作或重新生成课程；用户选择旧会话时关联切换课堂属于会话导航，不是 Agent 播放控制。
- 不提供联网搜索、代码执行、白板、语音输入或合成、复杂 Roundtable UI、Agent 人设自动生成。
- 不提供会话重命名、复制、合并、跨课堂聊天记忆、回收站或撤销删除；不提供登录、独立 Agent Worker、持久任务队列或关闭页面后持续执行的保证。
- 不承诺图执行断点续跑、跨页面模型调用恰好一次、固定回复耗时或无限自动重试。
- 不提供部分正文持久化、流事件重放或断点续传；逐字展示不增加离页后持续执行、自动重新生成或完整回答恢复之外的承诺。
- 不在本 spec 定义具体节点、接口、表结构、提示词、调用上限数值或施工步骤；这些由后续 plan / tasks 承接。

## 验收

- CD-1 WHEN 用户在可播放课堂中展开或收起右侧聊天窗口，THE SYSTEM SHALL 展开时暂停正在进行的讲解并保留画面与字幕，收起后不自动恢复播放，由用户手动继续。打开、关闭及读取记录不发起教师回复，不重播场景，不改变后台续生成顺序。
- CD-2 WHEN 用户发送问题后切换场景，THE SYSTEM SHALL 保持该问题与回复使用原会话、关联课堂及发送时的场景依据，并可辨认对应场景；同一会话下一条问题使用发送时的新场景，保留该会话历史。切场及内容刷新不把旧回复改挂到新场景或其他会话。
- CD-3 WHEN 用户提出概念解释、理解检查或应用实践需求，THE SYSTEM SHALL 结合当前场景与相关前文，分别路由给讲解老师、思考教练或应用教练，由一位教师回复并显示身份。同主题下“概念是什么意思”“我这样推理对吗”“在项目中怎么用”应体现对应职责；后续需求变化可在下一轮换教师，不强制轮流发言或同轮交接。
- CD-4 WHEN 回答需要更多课程信息，THE SYSTEM SHALL 由教师按需选择只读工具，取得本课当前场景、其他已保存内容或相关资料；不要求所有问题都调用工具，不把未生成内容当作已存在，不通过工具改写课程或学习记录。
- CD-5 WHEN 本课没有知识库，THE SYSTEM SHALL 仅凭可用对话配置及本课内容支持问答，不要求向量配置、不编造文档引用。已有知识库且本问题需要资料时，允许结合上下文形成检索问题，在信息不足时调整查询并补查；无需资料的问题不强制检索。
- CD-6 WHEN 教师使用检索资料回答，THE SYSTEM SHALL 将实际使用的本课片段关联到该条回复，展示来源文档、可用页码与片段；无相关依据时说明资料不足，不编造来源、不把检索结果当作必然正确。缺向量配置或检索失败时明确显示查询未完成，允许重试，不冒充无命中或有依据的成功回答。
- CD-7 WHEN 用户追问、表达理解或反馈仍不明白，THE SYSTEM SHALL 仅利用当前会话相关对话衔接回答、定位用户明确表达的困惑或调整讲法；指代不清时具体澄清。不同教师共享该会话必要上下文，历史选择与临时摘要不读取其他会话聊天，即使其属于同一课堂；摘要不替代原始记录、不虚构用户背景或已经掌握的结论。
- CD-8 WHEN 用户询问尚未提交的测验，THE SYSTEM SHALL 支持知识解释、提示与思路分析，不直接给出该题标准答案、完整解析或隐藏评分依据，相关上下文与工具读取遵守同一边界。提交后可讨论已存答案及可用反馈，不虚构尚未完成的批改结果，不改写正式答案、分数或状态。
- CD-9 WHEN 问题与完整回复保存成功后用户收起聊天、切场、切换会话、刷新或再次进入，THE SYSTEM SHALL 支持读取会话列表并恢复所选未删除会话的问题、回复、教师身份、所属场景及引用，不要求模型或检索服务可用，不自动重新生成回复；收起、切场与切换会话不清空已保存记录。刷新保持当前选择（包括未选择状态）；旧版记录按课堂归入“历史会话”，保留原始记录及执行状态，不重新生成或自动续跑。删除成功的会话不在恢复范围内。
- CD-10 WHEN 问题保存、路由、工具调用、检索、回复生成或保存失败，THE SYSTEM SHALL 区分未保存与已保存但未完成，保留相应输入或问题及已有记录，提供可理解的错误与重试入口。未保存或部分输出不标为完整已保存回复；重复触发或重试不重复追加同轮问题及已完成回复，结果不明时先读取核对。会话已成功删除时，不通过失败恢复或重试重新建立会话及消息。
- CD-11 WHEN 缺少本次所需模型配置、模型不支持所需能力或相关服务不可用，THE SYSTEM SHALL 明确说明本轮无法完成，不使用环境变量代替配置，不保存密钥，不阻塞已有课堂内容的观看、切场、历史聊天读取及其他可用操作。工具查找与模型调用须在有限步骤、重试和时间边界内结束或报错。
- CD-12 WHEN 服务端处理聊天、课程读取工具或资料检索，THE SYSTEM SHALL 校验会话存在、会话与课堂绑定，以及场景、问题、历史与引用归属，拒绝跨会话和跨课堂混用；同课堂其他会话也不能借用问题身份、恢复结果或聊天记忆。晚到回复仍归属原问题，不更新其他会话或覆盖新问题；已删除会话的在途结果和旧请求不得重新创建会话或消息。刷新不恢复未保存输出或自动重跑未完成问答。
- CD-13 WHEN 生成或播放场景，THE SYSTEM SHALL 不生成新的 `discussion` 动作；已有该动作不展示讨论话题、不打开聊天、不调用 Agent，也不据此强制暂停，其余有效讲稿与动作仍能继续。真实问答仅由用户主动发送问题发起。
- CD-14 WHEN 用户通过键盘、窄屏或深浅主题使用聊天，THE SYSTEM SHALL 保持展开、收起、输入、发送、查看引用、失败重试以及会话列表、新建、选择和删除确认可读可操作，明确区分用户与教师、处理中与失败状态，状态不只依赖颜色表达；聊天内容不作为可执行脚本运行。
- CD-15 WHEN 用户在课堂 A 新建会话，THE SYSTEM SHALL 建立固定关联 A 的独立会话，不继承其他会话聊天或摘要；同一课堂可新建多个会话。用户浏览课堂 B 后新建的会话关联 B，不改变已有会话与 A 的绑定。服务端从关联课堂安全读取资料，拒绝用其他课堂场景发问；创建失败不展示为创建成功。
- CD-16 WHEN 用户从会话列表打开已有会话，THE SYSTEM SHALL 展示其所属课堂并恢复该会话记录；当前显示另一课堂时同时切回会话关联课堂，课堂切换失败时明确反馈，不在课堂与会话不一致的状态下发问。普通进入且没有明确选择时恢复该课堂最近使用的会话，没有会话则显示空态，由用户手动新建；读取失败不冒充无会话。选择与读取不发起模型调用、不合并历史，旧会话晚到结果不污染新选会话。
- CD-17 WHEN 用户删除会话，THE SYSTEM SHALL 二次确认，取消不改变数据；删除成功后永久移除该会话及其聊天、回复、引用关联和执行记录，不删除课堂、场景、PDF 或正式测验数据，不提供回收站。删除当前会话后保留课堂画面并显示未选择会话的空态，不自动新建或选中其他会话；删除非当前会话不影响当前聊天。删除失败或结果不明时明确反馈且不冒充成功；删除成功后经刷新、晚到读取、生成写回、重复提交或显式重试均不能恢复已删除会话及消息，也不影响其他会话。
- CD-18 WHEN 普通问答开始生成最终正文，THE SYSTEM SHALL 在完整回答生成结束前持续传输可用正文增量，并在界面连续逐字呈现，不按整段显示或等完整回答后才开始动画；正确呈现中文、emoji 与 Markdown，标明生成中并显示末尾光标，积压时避免无必要的动画拖延。底部跟随输出，用户向上阅读时不强制拉回；已保存历史直接展示。教师身份与执行阶段来自服务端真实反馈，内部决策、推理、工具参数及结构化包装不混入正文；基础交互继续满足 CD-14。
- CD-19 WHEN 本轮触发测验保护检查，THE SYSTEM SHALL 在外发正文前由服务端核对保护要求，先完整生成并通过适用校验，再允许正文发送并逐字呈现；等待期间可显示真实阶段，首字允许延后。检查拒绝或未通过时不向浏览器发送被拒绝正文，不以先展示后撤回代替保护，未提交题与待批改状态的边界继续满足 CD-8。
- CD-20 WHEN 正文正在逐字展示、流中断、结束通知丢失或发生切场、切会话、重试与删除，THE SYSTEM SHALL 将临时正文、执行反馈、显示队列及结束结果限定到原会话、问题与本次执行；旧事件和旧队列不污染新回复或复活已删除会话。部分正文、流关闭及动画结束不标为完成或已保存；仅数据库确认完整结果后标为已保存，结果不明先读取核对且不自动重跑。刷新仅恢复已保存记录，继续满足 CD-2、CD-9、CD-10、CD-12、CD-17。

## 系统不变量

- LangGraph 用于问答编排；本轮仅选择一位固定教师，角色职责不由模型随意重写。
- 问答编排与课程生成编排独立，不共享运行状态，不以聊天推进课程生成或播放。
- 会话固定关联创建时的课堂，每轮问题绑定所属会话及发送时该课堂内的场景；课程事实来自本课已保存内容，客户端传入的身份或模型声称的引用不替代服务端校验。
- 问答工具只读，测验答案与评分依据的访问遵守提交状态边界；聊天练习不写正式测验结果。
- PostgreSQL 是已保存聊天的唯一持久化事实来源；会话摘要及浏览器缓存不替代原始记录。
- 无知识库可正常问答；需要检索才使用向量配置；失败、未命中与有依据回答应明确区分。
- 只有完整且成功保存的回复才可标为已保存；恢复已有回复不重新调用模型。
- 流式正文与逐字显示是临时呈现，不形成另一套持久化事实；测验保护检查必须先于受保护正文外发，流事件及显示队列沿用本轮归属与执行隔离。
- 聊天历史选择与摘要按会话隔离，不因课堂相同而合并；无登录，不把会话身份当成用户认证或私有权限，不按昵称建立独立学习档案。
- 会话删除不删除课堂资料或正式测验记录；删除成功优先于旧执行写回，旧请求不得复活已删除会话或消息。

## 非功能约束

- 主要交互可用键盘完成；右侧聊天展开后仍可辨认当前课程和场景，窄屏允许适配展示。
- 工具调用、补充检索与失败重试有明确执行边界，不能依靠模型无限自行循环；具体数值在实施方案中确定。
- 错误信息不包含密钥、敏感请求头或堆栈；用户能区分等待回复、失败与已保存状态。
- 不以教师身份、模型自评或引用数量宣称回答必然正确或学习效果已经得到证明。

- 治理约束：[[intent]]、[[adr-001]]、[[adr-002]]、[[adr-003]]、[[adr-004]]；[[adr-007]] 记录问答编排与权限边界，目前为 proposed，待审查后确认。
