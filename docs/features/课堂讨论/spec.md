# 课堂讨论

## 承诺

课堂已定稿并保存完整首场，用户在 `/classroom/[id]` 观看已就绪场景时，可主动展开右侧聊天窗口，围绕本课程与当前场景提问、追问或表达自己的理解。课堂不再通过 `discussion` 教学动作提出话题或发起对话；新场景不生成该动作，旧场景中已有的该动作不触发讨论、聊天或强制暂停，其他有效讲稿与动作仍可播放。

聊天窗口由用户主动展开和收起。展开时暂停正在进行的讲解，保留当前画面与字幕；收起后保持暂停，由用户手动继续。展开、收起或读取聊天记录不自动发送问题、不调用教师生成回复，也不重播当前场景。后台续生成仍按其独立流程运行。

### 三名固定教师与自动路由

用户面对同一课堂中的教学团队发问，不需要先手动选择教师。三名教师的职责固定，不自动生成人设：

- **讲解老师**：解释概念、拆解当前内容、补充必要的前置知识，帮助用户听懂。适合“是什么”“为什么”“这句话是什么意思”。
- **思考教练**：分析用户表达的理解与推理，指出具体混淆或遗漏，通过适量追问帮助用户理清思路。适合“我这样理解对吗”“我的思路哪里有问题”。直接提问应得到回答，不以连续反问代替答疑。
- **应用教练**：把课程知识连接到案例、练习或实际项目，分析用户的应用尝试。适合“实际怎么用”“给我一个例子”“让我练一下”。聊天内的练习不成为正式测验，不产生或修改正式成绩。

系统通过 LangGraph 编排，每轮根据用户问题、发送时的课程与场景、相关对话判断由哪位教师回答；不能仅凭孤立关键词忽略前文。本轮由一位教师主导并输出回复，界面标明其身份。用户后续问题的学习需求变化时，下一轮可以选择另一位教师。首版不包含同轮多教师发言、教师间主动交接或任务委派，也不要求三名教师轮流出现。

### 场景上下文、工具与资料

每条问题以发送时所在的场景作为本轮上下文，界面可辨认该场景。发送后切换场景，不改变这条问题及其回复的场景依据；下一条问题使用发送时的新场景。同一课堂保留连续的聊天历史，教师应结合前文理解“它”“刚才那个”等指代；无法明确时提出具体澄清问题，不编造用户所指。

教师可以按需使用只读工具，取得本课当前场景、其他已保存内容或本课 PDF 的相关片段。工具使用由问题需要决定，不要求每轮调用全部工具。读取与检索由服务端校验课堂归属，教师不能通过工具修改大纲、场景、播放位置、用户答案或测验结果。尚未生成的内容不能当作已保存场景引用。

无知识库时，教师仍可基于课程需求、定稿大纲、已保存场景与相关对话回答，不要求向量配置，也不伪造文档引用。有知识库且问题需要资料依据时，教师可结合上下文形成检索问题、读取相关片段；信息不足时可以调整查询后补查。检索与工具调用必须有执行边界，不能无限查找。已有知识库不意味着所有问题都必须检索。

使用 PDF 片段支撑回答时，展示与本条回复关联的真实来源，至少能辨认来源文档、可用页码与相关片段；不能把检索命中直接当作结论正确的证明。没有相关依据时说明资料不足，区分课程资料内容与一般性解释，不编造引用、不把文档全文送入提示词。检索服务失败与“未找到相关资料”须明确区分，失败不得被伪装成检索成功或无相关结果。

### 会话记忆与测验边界

教师共享本课堂必要的会话上下文，包括已经解释的内容、用户明确表达的困惑、使用过的例子和未解决的问题。对话较长时可以整理摘要，为本轮选择相关历史；摘要不能替代原始聊天记录，也不能把模型对用户能力的猜测当成事实。用户说“还是没懂”时，应结合之前的讲法调整解释，不机械重复。未填写昵称或背景时不编造学习者信息。

测验尚未提交时，教师可解释相关知识、提供提示或分析用户思路，不直接提供该题标准答案、完整解析或隐藏评分依据；即使用户直接索要，也保持这一边界。该边界同时适用于上下文准备、历史选择、其他场景读取和资料检索，不能把隐藏答案作为可随意取用的工具结果。提交后可讨论已保存的答案与可用反馈；批改尚未完成时不虚构分数、批改成功或正式评语。主动重做不清除已经保存的聊天，也不承诺让用户忘记此前看过的答案；新一轮作答仍按播放与测验的重做规则处理。

### 保存、失败与恢复

已保存的用户问题、教师完整回复、教师身份、问题所属场景与回复引用归属于本课堂，持久保存在 PostgreSQL。收起聊天或切场不清除已保存记录；刷新或凭课堂 id 再次进入，可读取恢复。读取历史不要求模型或向量服务可用，也不自动重新生成已有回复。当前版本无登录，同一课堂 id 对应同一份聊天记录，不按昵称区分学习档案，不扩展多会话管理。

问题保存失败时保留输入，明确提示未保存并允许重试；已保存问题的路由、工具调用、检索或回复生成失败时，保留问题与既有聊天，说明本轮未完成并允许重试。完整回复未成功保存时，不标为已保存或可恢复；部分输出不当作完整回复。重复点击、重试或响应丢失后的恢复不应为同一轮重复追加问题或已完成回复；结果不明时先核对已保存结果，已完成则直接恢复。

本单元承诺恢复已保存聊天，不承诺恢复未发送输入、未保存输出或模型执行到一半的位置，也不承诺离开页面后继续完成问答。收起窗口不清空记录；无论请求是否已经结束，晚到结果都只能归属原课堂、原问题和原场景，不能更新其他课堂或变成新问题的回复。刷新恢复后不因旧请求未完成而自动启动新一轮模型调用。

对话与向量配置分别来自当次请求，不读取服务端环境变量兜底，不把密钥存入聊天、课堂、会话摘要或执行记录。只有实际需要检索时才要求可用向量配置；缺配置或检索失败时明确提示本次资料查询未完成，不悄悄降级为声称有资料支持的回答。对话模型不能完成路由、工具调用或生成时，应提示本轮失败，不伪装成功。配置、聊天读取或问答失败不阻塞课堂已有内容的观看、切场和其他可用操作。

## 非目标

- 不生成或执行 `discussion` 教学动作，不主动弹出讨论、不在无人提问时自主发言。
- 不提供手动选教师、同轮多教师发言、教师间 Handoff / Delegation、并行辩论或独立评审 Agent。
- 不提供正式测验出题与判分、聊天练习成绩、学习统计、掌握度结论或跨课程长期学习档案。
- 不修改已定稿课程、场景、讲稿与用户答案，不通过聊天驱动播放动作或重新生成课程。
- 不提供联网搜索、代码执行、白板、语音输入或合成、复杂 Roundtable UI、Agent 人设自动生成。
- 不提供多会话管理、登录、独立 Agent Worker、持久任务队列或关闭页面后持续执行的保证。
- 不承诺图执行断点续跑、跨页面模型调用恰好一次、固定回复耗时或无限自动重试。
- 不在本 spec 定义具体节点、接口、表结构、提示词、调用上限数值或施工步骤；这些由后续 plan / tasks 承接。

## 验收

- CD-1 WHEN 用户在可播放课堂中展开或收起右侧聊天窗口，THE SYSTEM SHALL 展开时暂停正在进行的讲解并保留画面与字幕，收起后不自动恢复播放，由用户手动继续。打开、关闭及读取记录不发起教师回复，不重播场景，不改变后台续生成顺序。
- CD-2 WHEN 用户发送问题后切换场景，THE SYSTEM SHALL 保持该问题与回复使用发送时的场景依据，并可辨认对应场景；下一条问题使用发送时的新场景，保留同课堂历史。切场及内容刷新不把旧回复改挂到新场景。
- CD-3 WHEN 用户提出概念解释、理解检查或应用实践需求，THE SYSTEM SHALL 结合当前场景与相关前文，分别路由给讲解老师、思考教练或应用教练，由一位教师回复并显示身份。同主题下“概念是什么意思”“我这样推理对吗”“在项目中怎么用”应体现对应职责；后续需求变化可在下一轮换教师，不强制轮流发言或同轮交接。
- CD-4 WHEN 回答需要更多课程信息，THE SYSTEM SHALL 由教师按需选择只读工具，取得本课当前场景、其他已保存内容或相关资料；不要求所有问题都调用工具，不把未生成内容当作已存在，不通过工具改写课程或学习记录。
- CD-5 WHEN 本课没有知识库，THE SYSTEM SHALL 仅凭可用对话配置及本课内容支持问答，不要求向量配置、不编造文档引用。已有知识库且本问题需要资料时，允许结合上下文形成检索问题，在信息不足时调整查询并补查；无需资料的问题不强制检索。
- CD-6 WHEN 教师使用检索资料回答，THE SYSTEM SHALL 将实际使用的本课片段关联到该条回复，展示来源文档、可用页码与片段；无相关依据时说明资料不足，不编造来源、不把检索结果当作必然正确。缺向量配置或检索失败时明确显示查询未完成，允许重试，不冒充无命中或有依据的成功回答。
- CD-7 WHEN 用户追问、表达理解或反馈仍不明白，THE SYSTEM SHALL 利用本课堂相关对话衔接回答、定位用户明确表达的困惑或调整讲法；指代不清时具体澄清。不同教师共享必要上下文；摘要不替代原始记录、不虚构用户背景或已经掌握的结论。
- CD-8 WHEN 用户询问尚未提交的测验，THE SYSTEM SHALL 支持知识解释、提示与思路分析，不直接给出该题标准答案、完整解析或隐藏评分依据，相关上下文与工具读取遵守同一边界。提交后可讨论已存答案及可用反馈，不虚构尚未完成的批改结果，不改写正式答案、分数或状态。
- CD-9 WHEN 问题与完整回复保存成功后用户收起聊天、切场、刷新或再次进入，THE SYSTEM SHALL 恢复本课堂已保存的问题、回复、教师身份、所属场景及引用，不要求模型或检索服务可用，不自动重新生成回复；收起与切场不清空记录。
- CD-10 WHEN 问题保存、路由、工具调用、检索、回复生成或保存失败，THE SYSTEM SHALL 区分未保存与已保存但未完成，保留相应输入或问题及已有记录，提供可理解的错误与重试入口。未保存或部分输出不标为完整已保存回复；重复触发或重试不重复追加同轮问题及已完成回复，结果不明时先读取核对。
- CD-11 WHEN 缺少本次所需模型配置、模型不支持所需能力或相关服务不可用，THE SYSTEM SHALL 明确说明本轮无法完成，不使用环境变量代替配置，不保存密钥，不阻塞已有课堂内容的观看、切场、历史聊天读取及其他可用操作。工具查找与模型调用须在有限步骤、重试和时间边界内结束或报错。
- CD-12 WHEN 服务端处理聊天、课程读取工具或资料检索，THE SYSTEM SHALL 校验课堂、场景、问题、历史与引用归属，拒绝跨课堂混用；晚到回复仍归属原问题，不更新其他课堂或覆盖新问题。刷新不恢复未保存输出或自动重跑未完成问答。
- CD-13 WHEN 生成或播放场景，THE SYSTEM SHALL 不生成新的 `discussion` 动作；已有该动作不展示讨论话题、不打开聊天、不调用 Agent，也不据此强制暂停，其余有效讲稿与动作仍能继续。真实问答仅由用户主动发送问题发起。
- CD-14 WHEN 用户通过键盘、窄屏或深浅主题使用聊天，THE SYSTEM SHALL 保持展开、收起、输入、发送、查看引用及失败重试可读可操作，明确区分用户与教师、处理中与失败状态，状态不只依赖颜色表达；聊天内容不作为可执行脚本运行。

## 系统不变量

- LangGraph 用于问答编排；本轮仅选择一位固定教师，角色职责不由模型随意重写。
- 问答编排与课程生成编排独立，不共享运行状态，不以聊天推进课程生成或播放。
- 每轮问题绑定发送时的课堂与场景；课程事实来自本课已保存内容，客户端传入的身份或模型声称的引用不替代服务端校验。
- 问答工具只读，测验答案与评分依据的访问遵守提交状态边界；聊天练习不写正式测验结果。
- PostgreSQL 是已保存聊天的唯一持久化事实来源；会话摘要及浏览器缓存不替代原始记录。
- 无知识库可正常问答；需要检索才使用向量配置；失败、未命中与有依据回答应明确区分。
- 只有完整且成功保存的回复才可标为已保存；恢复已有回复不重新调用模型。
- 无登录，同一课堂 id 共享同一套课堂聊天；不按昵称建立独立记录。

## 非功能约束

- 主要交互可用键盘完成；右侧聊天展开后仍可辨认当前课程和场景，窄屏允许适配展示。
- 工具调用、补充检索与失败重试有明确执行边界，不能依靠模型无限自行循环；具体数值在实施方案中确定。
- 错误信息不包含密钥、敏感请求头或堆栈；用户能区分等待回复、失败与已保存状态。
- 不以教师身份、模型自评或引用数量宣称回答必然正确或学习效果已经得到证明。
