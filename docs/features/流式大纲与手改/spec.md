# 流式大纲与手改

## 承诺

课堂已由「创建课堂」持久化。用户在该课的生成预览中看到大纲逐条出现，并可在确认前修改已出现场景的标题、描述与要点，调整场景顺序，以及新增或删除场景。

生成使用该课已保存的 `requirements`。对话配置与向量配置各自包含 Key、端点与模型名，只来自当次请求，不读取服务端环境变量，也不能互相代替。无知识库时只使用对话配置。知识库已就绪时，检索使用向量配置，生成仍使用对话配置。场景类型只有 `slide` 与 `quiz`。每条场景含标题、描述、要点。已有 `quiz` 的测验配置随该场景留在当前页面；新增的 `quiz` 在页面上带有测验配置。模型给出的授课语言指令与大纲一起留在当前页面。

大纲、手改和授课语言指令在用户确认前只存在当前页面。本单元不把它们写入数据库。

生成页主路径对有 PDF 且知识库未就绪的草稿先执行 [[文档入库]]；入库确认就绪后才启动大纲。下列无知识库分支仍描述大纲能力的接口契约，不代表生成页可以自动跳过已上传 PDF。

## 非目标

- 不确认大纲，不把大纲或授课语言指令写入数据库，不生成场景，不进入播放或讨论。
- 不解析 PDF、不向量化、不把文档全文送入提示词。
- 不提供模型设置界面。设置、本机保存和统一请求头由 [[配置模型]] 承担；本单元使用该单元从已保存配置组装的请求头，不再使用联调阶段写死的开发配置。服务端契约不变：当次请求缺对话配置，或知识库已就绪但缺向量配置时，拒绝本次生成；缺配置不阻塞首页建立草稿课堂。
- 手改不再次调用模型。
- 不登录。不接受 `interactiveMode`。
- 不做互动或 PBL 场景、联网搜索、AI 图 / 视频、Tool Chat 侧栏改大纲。
- 首页历史列表不在本单元。

## 验收

- OL-1 WHEN 已有合法草稿课堂，且当次请求带有可用的 Chat 模型配置，THE SYSTEM SHALL 按该课 `requirements` 在生成预览中流式展示场景大纲。每条在整份结束前即可看见，类型仅为 `slide` 或 `quiz`，并含标题、描述、要点。无知识库时不检索、不报错。此次不写入大纲与授课语言指令。
- OL-2 WHEN 大纲已在当前页面展示，THE SYSTEM SHALL 允许在确认前修改已有场景的标题、描述与要点。修改只留在当前页面，不调用模型，不写入数据库。
- OL-6 WHEN 大纲已在当前页面展示，THE SYSTEM SHALL 允许在确认前调整场景顺序，以及新增或删除场景。新增场景类型仅为 `slide` 或 `quiz`，并含标题、描述、要点；`quiz` 另含测验配置。调序与增删不改动其余场景的类型与测验配置。这些修改只留在当前页面，不调用模型，不写入数据库。
- OL-3 WHEN 课堂知识库已就绪，且当次请求另带可用的向量模型配置，THE SYSTEM SHALL 用该向量配置检索本课并生成大纲，且不把文档全文送入提示词，不编造文档引用。知识库未就绪时只按提示词与已保存的昵称、背景生成，不要求向量配置。
- OL-4 WHEN 用户在大纲尚未确认时刷新或凭课堂 id 再次打开，THE SYSTEM SHALL 恢复已保存的课堂需求与资料，且不返回本次生成或手改的大纲与授课语言指令。
- OL-5 WHEN 课堂不存在、未配置对话模型、知识库已就绪但未配置向量模型，或模型没有产出可解析大纲，THE SYSTEM SHALL 中止本次生成，展示可理解的错误并允许重试，且不写入大纲。

## 系统不变量

- 没有已存在的课堂，不得生成大纲。
- 场景类型只有 `slide` 与 `quiz`。
- 确认前，大纲、手改与授课语言指令只存在当前页面。不写入 `stage.outlines` 与 `languageDirective`，不建大纲表，不写 Plan 蓝图列。
- 手改可以修改已有场景的标题、描述、要点，也可以调整顺序、新增或删除场景。手改不调用模型。新增场景类型只有 `slide` 与 `quiz`。
- 对话配置与向量配置各自包含 Key、端点与模型名，互不代替。
- 无 PDF 或知识库未就绪时，不要求向量配置。大纲生成只凭对话配置完成。
- 昵称与背景都未填时，不编造学习者画像。
- 无登录。持有课堂 id 即可生成。

## 非功能约束

- 失败信息须可理解，不得包含堆栈或密钥。
