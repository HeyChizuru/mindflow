# 确认大纲并生成首屏

## 承诺

课堂已由「创建课堂」持久化。大纲、手改与授课语言指令已在该课的生成页上，且尚未写入数据库。

用户在生成页确认时，系统把当时页面上的大纲与授课语言指令写入该课堂。写入的是页面上的手改结果，不重新调用大纲模型。写入成功后，本课视为定稿。定稿后不再手改，也不再重新流式生成大纲。

生成页只有收到大纲流的 `done` 后才允许提交确认，并在请求中声明 `outlineStreamCompleted: true`。服务端校验该声明；缺失或值不为 true 时拒绝确认。服务端不保存大纲流运行状态，不独立验证客户端声明是否对应真实的流结束事件。

定稿之后，仍在同一生成页只生成大纲中的第 1 个场景。幻灯片包含该页画布上的元素，每项有位置、样式与文案。测验按题型保存完整内容：单选与多选题包含题目、选项、正确答案与解析；简答题包含题目、参考解析与评分依据，不要求选项或预设答案，供播放页测验使用。同时生成一组动作，供播放引擎以后按顺序执行。常见动作有：讲稿（字幕文字，不是音频，也不合成语音）、高亮或激光（指向画面上的某个元素）、讨论（话题与引导），以及交互组件的高亮、设状态与标注。本单元只生成并保存，不播放、不批改、不发起讨论。第 2 个及以后的场景不生成。缺少该页元素、未满足对应题型的完整性规则，或缺少讲稿时，第 1 个场景不算已生成。

生成使用该课已保存的需求、已确认的大纲与授课语言指令。对话配置与向量配置各自包含 Key、端点与模型名，只来自当次请求，不读取服务端环境变量，也不能互相代替。无知识库时只使用对话配置。知识库已就绪时，检索使用向量配置，生成仍使用对话配置，且不把文档全文送入提示词。

当次请求若不满足生成第 1 个场景的配置前提，拒绝确认，不写入大纲。配置满足时先写入，再生成第 1 个场景。

「只生成第 1 个场景」是本单元生成页流程的范围限制。请求组装与生成分开：生成页前端从已保存的课堂与定稿准备生成依据，选择第一份大纲，先请求场景内容接口，再携带内容请求讲解动作接口；首场的两步调用由前端串联。[[后台续生成]] 则由其调用方按自身流程传入尚未完成的大纲与前序讲稿。

两个后端接口各自负责实际的模型调用和生成工作，只处理本次请求指定的场景，不决定下一场，不接收首屏 / 后台来源标记。内容接口返回待用于动作生成的内容，不保存半成品场景；动作接口生成动作后，将内容与动作组装、校验，并保存为完整场景，只有保存成功或读到该目标已有的完整场景才返回成功结果。保存时机属于动作接口内部流程，前端不另外提交场景保存请求。动作接口可根据传入的全部大纲计算当前页码与总页数，并使用传入的前序场景讲稿保持连贯；知道课程位置不等于参与调度。目标必须属于本课堂已确认大纲，输入仍须校验。本单元不因此启动其余场景的生成、调度或整课状态管理。

首场保存成功后，进入教室的页面跳转由前端控制；播放页路径、页面实现及播放能力由 [[课堂播放与测验]] 定义，本阶段后端不负责页面跳转。

## 非目标

- 不重新流式生成大纲。确认后不修改标题、描述、要点，不调整顺序，不增删场景。
- 不生成第 2 个及以后的场景，不在生成页续生成。其余场景由播放页上的 [[后台续生成]] 负责。
- 不实现播放页或播放引擎，不播放、不批改测验、不发起讨论；首场保存成功后的前端跳转与播放页衔接，不改变这些能力的单元归属。
- 不合成语音。不解析 PDF，不向量化，不把文档全文送入提示词。
- 不提取或映射 PDF 图片，不使用模型视觉输入，不提供白板专用能力；保留普通画布元素与已约定的讲稿、讨论及组件动作。
- 不提供模型设置界面，本单元前端也不读 localStorage。联调阶段把对话头写死在客户端；知识库已就绪时再写死向量头。项目跑通后，首页是否已配置模型由 [[配置模型]] 校验，再改为从 localStorage 组装同一套请求头。服务端契约不变：当次请求缺对话配置，或知识库已就绪但缺向量配置时，拒绝本次确认。
- 不登录。不接受 `interactiveMode`。
- 不新增互动或 PBL 场景类型。交互组件只作为幻灯片或测验动作出现。不做联网搜索、AI 图 / 视频、Tool Chat 侧栏改大纲、Plan 蓝图与评审闭环。
- 首页历史列表不在本单元。

## 验收

- CF-1 WHEN 生成页上已有至少一条尚未入库的大纲，大纲流已经结束，且当次请求带有可用的对话配置，THE SYSTEM SHALL 在用户确认时把当时页面上的大纲与授课语言指令写入该课堂，并将该课视为定稿。写入的是确认前页面上的那份大纲。此次不调用大纲模型。
- CF-2 WHEN 大纲与授课语言指令已按 CF-1 写入，THE SYSTEM SHALL 由生成页前端选择第 1 个场景的大纲，依次请求内容接口与动作接口；后端分别执行实际生成，动作接口组装、校验并保存完整场景后返回成功，前端不另发保存请求。幻灯片包含该页画布元素（位置、样式、文案）。测验中的单选与多选题包含题目、选项、正确答案与解析；简答题包含题目、参考解析与评分依据，不要求选项或预设答案。同时生成供播放引擎按顺序执行的动作，其中包括讲稿，并可以包含高亮或激光、讨论，以及交互组件动作。不合成语音，不在本单元播放或发起讨论，不生成其余场景。
- CF-3 WHEN 课堂知识库已就绪，且当次请求另带可用的向量配置，THE SYSTEM SHALL 用该向量配置检索本课后生成第 1 个场景，且不把文档全文送入提示词，不编造文档引用。知识库未就绪时只凭对话配置、已保存需求与已确认大纲生成，不要求向量配置。
- CF-4 WHEN 确认与第 1 个场景均已成功，用户刷新或凭课堂 id 再次打开，THE SYSTEM SHALL 恢复已写入的大纲、授课语言指令与第 1 个场景。本单元流程不新增其余场景；其余场景是否已由后台续生成保存，不影响首屏恢复。不得重新生成一份大纲来代替已确认的内容。
- CF-5 WHEN 课堂不存在、页面上没有可确认的大纲、大纲流尚未结束、未配置对话模型，或知识库已就绪但未配置向量模型，THE SYSTEM SHALL 拒绝本次确认。大纲流尚未结束由生成页禁止提交保证；服务端在请求缺少 `outlineStreamCompleted: true` 声明时拒绝确认，不独立验证该声明是否对应真实的流结束事件。课堂保持草稿，不写入大纲与授课语言指令，不生成任何场景。展示可理解的错误并允许重试。
- CF-6 WHEN 大纲与授课语言指令已经写入，但第 1 个场景生成或保存失败、缺少该页元素、未满足 CF-2 对应题型的完整性规则，或缺少讲稿，THE SYSTEM SHALL 保持该课定稿和已写入的大纲，不回滚大纲，不生成其余场景。展示可理解的错误，并允许只重试第 1 个场景；保存失败不得返回生成成功。响应丢失后，以数据库中是否存在完整场景作为恢复依据。
- CF-7 WHEN 该课大纲已经写入，THE SYSTEM SHALL 拒绝再次改写大纲、手改或重新流式生成大纲。第 1 个场景尚未完整生成时，生成页只允许按 CF-6 重试该场景；不把这一流程限制写成通用场景生成接口只能生成首屏。

## 系统不变量

- 没有已存在的课堂，或页面上没有至少一条大纲，不得确认。
- 大纲流尚未结束时，生成页不得提交确认；只有收到 `done` 后才能携带 `outlineStreamCompleted: true` 提交。服务端拒绝缺失或不为 true 的声明，不独立验证客户端的流结束状态。
- 确认写入的是当时页面上的大纲与授课语言指令，不是模型重新生成的另一份。页面上没有授课语言指令时，不编造一条。
- 确认请求失败时，不留下半成品大纲，课堂仍是草稿。
- 大纲与授课语言指令写入成功即定稿。此后不手改，不重跑大纲流。
- 本单元只持久化第 1 个场景。幻灯片须有该页画布元素（位置、样式、文案）；测验中的选择题须有题目、选项、正确答案与解析，简答题须有题目、参考解析与评分依据。场景还须有讲稿。缺少对应必填内容则该场景不算已生成。
- 前端决定目标大纲与两次请求的调用顺序；后端接口执行实际生成，动作接口负责完整场景的组装、校验与保存。内容生成成功不等于场景已保存，不增加前端单独提交保存或后端统一调度首场的步骤。
- 动作供播放引擎以后按顺序执行。讲稿是字幕文字，不是音频。本单元不播放、不批改、不发起讨论。
- 场景类型只有 `slide` 与 `quiz`。
- 大纲存在该课堂的 `outlines` 与 `languageDirective` 上。不建大纲表，不写 Plan 蓝图列。
- 对话配置与向量配置各自包含 Key、端点与模型名，互不代替，只来自当次请求。
- 无知识库时不要求向量配置。
- 昵称与背景都未填时，不编造学习者画像。
- 无登录。持有课堂 id 即可确认并生成。

## 非功能约束

- 失败信息须可理解，不得包含堆栈或密钥。
