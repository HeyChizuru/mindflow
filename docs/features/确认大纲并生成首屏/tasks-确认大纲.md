# 阶段一：确认大纲

依据 [spec](./spec.md) 与 [plan 阶段一](./plan.md#阶段一确认大纲)。本阶段完成确认、定稿读取与页面恢复，不生成场景；CF-4 只覆盖大纲和语言指令恢复，完整首屏恢复留到阶段二。

## 现有实现

确认接口、原子条件写入、大纲列表校验已存在，直接复用。当前生成页每次进入都会开大纲流，编辑器缺少确认入口与定稿状态，服务端尚无定稿读取及大纲流门禁。

## T1 — 后端

- [ ] 在 `lib/types/stage-generation.ts`、`lib/validators/stage-generation.ts` 补充生成页读取 DTO：草稿返回课堂 ID、知识库开关和草稿状态，不返回大纲；定稿另返回已保存大纲和可空语言指令。
- [ ] 在 `lib/services/stage-generation.ts` 补读取方法，校验存量大纲，不重新生成或补默认语言指令。
- [ ] 新增 `GET /api/stages/{id}/generation-preview`，不要求模型头、不调用模型，使用不缓存响应；保留现有课堂 GET / POST 契约。
- [ ] 大纲 SSE 复用已有未定稿规则，开流与解析模型配置之前检查课堂；定稿请求返回 409，不调用对话或向量模型。
- [ ] 回归确认接口：配置前置失败无写入，成功保存页面手改结果，重复与并发确认不覆盖定稿。

## T2 — 前端静态

- [ ] 复用 `OutlinesEditor` 与现有 Button，增加确认回调、提交中和只读状态；流未结束、空列表或大纲不合格时禁用确认。
- [ ] 确认中锁定编辑与重复提交；失败保留当前手改内容，展示可理解错误并允许重试。
- [ ] 定稿后展示明确成功状态和只读大纲，隐藏确认、增删及调序入口；不展示首屏生成或播放按钮。

## T3 — 联调

- [ ] 在 `lib/client/generate/` 封装确认与生成页读取，校验响应；模型头沿用当前开发联调配置，不读 localStorage。
- [ ] 页面先读取草稿 / 定稿状态：草稿才开大纲 SSE，定稿直接恢复；只有收到 `done` 才允许提交 `outlineStreamCompleted: true`。
- [ ] 确认成功使用服务端返回的已保存大纲锁定页面；确认响应丢失或被另一页面抢先确认时，重新读取状态，若已定稿则恢复而不继续编辑或重新生成。
- [ ] 切换课堂或离开页面时中止旧请求，忽略过时回调，避免旧课堂或旧大纲事件覆盖当前状态。

## 验证

- [ ] API：草稿读取不返回大纲；定稿读取准确恢复手改内容与语言指令，缺省语言指令仍为 null；不要求模型配置。
- [ ] API：坏 ID、假课堂、空列表、流完成声明不为 true、缺模型配置等失败不写库；定稿再次确认与开大纲流均被拒绝。
- [ ] 页面：流中确认禁用；流结束后修改、调序并确认，提交中不可重复操作，成功后只读。
- [ ] 页面：刷新与再次进入只恢复定稿，不触发大纲或场景模型；确认失败可重试且保留手改。
- [ ] 页面：覆盖响应丢失、重复确认、加载失败及重试；服务端拒绝不能被前端误显示为成功。
- [ ] 定向类型检查与相关 lint；本阶段不重复运行已知受未适配生成代码阻断的全量构建。
