## 缺陷记录

### BG-UI-1：短横屏画布高度不足（BG-5、非功能约束）

- 复现：844×390，目录展开，原工具栏两行及字幕固定高度，与页头叠加后画布仅剩很小高度；临时展示页另有 40px 控制条，去除此条后仍高度不足。
- 影响：画布内容缩成很小区域，不利于继续观看；状态与保存数据无损。
- 修复方向：仅在短视口允许主区纵向滚动并保留画布最小可用空间，工具栏、字幕与恢复按钮均可到达；桌面保持原弹性布局。

### BG-REC-1：成功重读后仍显示读取失败（BG-6、BG-7）

- 复现：实际 ClassroomSession 首次读取成功，第二次读取 503，第三次读取成功。受控脚本输出失败后及恢复后的 notice.title 都是「课堂更新失败」。
- 影响：已恢复的目录继续显示失败文案与重读入口，容易误判保存结果。
- 修复：给临时会话的读取失败提示增加来源标识，仅在有效读取合并成功时清除此类提示，保留其他播放、冲突和位置提示。

### BG-UI-2：不同来源提示被优先级覆盖（BG-5、BG-6）

- 复现：会话同时有 positionNotice 和 notice，播放也有 actionNotice；PlaybackChromeRoot 原表达式只选择 positionNotice，其他提示及恢复入口没有传给视图。
- 影响：生成恢复与位置保存失败并存时，用户看不到全部相关反馈。
- 修复：视图增加可选 notices 列表并兼容既有 notice，播放外壳按来源分别传入，共用已设上限的滚动区，不改写各操作语义。
