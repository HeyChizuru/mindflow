# 文档入库

## 承诺

2026-10-28：用户确认主路径规格与计划，授权不展开 task 直接实施，并授权完成联调、更新状态和提交。生成页接线、服务端执行状态及 DI-1～DI-10 已完成本地验收，交付状态为 `verified`；真实链路、受控故障、清理与生产环境限制见 [验收记录](./验收记录.md)。

课堂已由「创建课堂」持久化。若该课保存了一份 PDF，本单元读取该原件，解析文本、按页切块并写入向量，使知识库就绪。无 PDF 的课不进入本单元。

入库是一次请求。请求成功返回前，知识库不得标为就绪。成功时返回课堂 id、文档 id、页数、去掉空白后的字符数、切块数，且 `hasKnowledgeBase` 为 `true`。向量模型配置包含自己的 Key、端点与模型名，只来自当次请求，不读取对话配置，也不读取服务端环境变量中的密钥。

解析正文去掉空白后少于 200 字，视为无法入库。写入的向量必须是 1024 维。

### 生成页主路径

创建课堂后，生成页依据服务端保存的课堂、文档和定稿状态决定下一步，不依赖首页的临时文件状态。草稿课堂没有 PDF 时直接进入原有大纲流程；有 PDF 且知识库未就绪时先处理资料，成功并确认知识库就绪后才开始大纲。已就绪时不因进入或刷新页面重新入库。

处理期间展示真实的「正在处理资料」阶段，不把一次请求推测成解析、向量化百分比或虚构进度。入库失败时说明原因，保留课堂与原件，提供设置入口和显式重试；不自动跳过 PDF 继续生成大纲。保存设置不会自动重试，显式重试使用当前已保存的向量配置；已发起的入库继续使用当次配置。

刷新、断连或请求结果不明确时，先读取服务端状态：确认就绪后继续；未确认结果时不显示成功或自动跳过，允许用户核对及恢复。多页面和重复请求不得导致不完整切块被标为就绪，也不得让过期执行覆盖较新的成功结果；无法确认时须明确提示，不把进行中的工作当成明确失败。

历史上已定稿但 PDF 尚未入库的课堂，打开或恢复时不自动补入，也不重跑已确认的大纲。主动补入入口及其对已有课程的影响另行决定。

## 非目标

- 不接收新文件，不创建课堂，不重做 PDF 类型、空文件与 50MB 校验。
- 不提供模型设置界面。缺向量配置时只拒绝本次入库。
- 不生成大纲，不把全文送入大纲提示词，不抽取 PDF 中的图片。
- 不实现课堂讨论，也不在回答中展示文档引用。
- 不登录，不接受第二份 PDF、ZIP 或 PPTX。
- 不提供跳过已上传 PDF 继续生成的入口，不提供已定稿历史课堂的主动补入入口。
- 本次不新增向量模型身份记录、兼容性匹配或知识库重建入口；同为 1024 维的不同模型可能不报错但影响检索，后续单独决定。

## 验收

- DI-1 WHEN 课堂已有一份已保存的 PDF，且当次请求带齐向量模型配置，THE SYSTEM SHALL 解析、按页切块、写入 1024 维向量，返回页数、去掉空白后的字符数与切块数，并将 `hasKnowledgeBase` 置为 `true`。此次不调用对话模型，不生成大纲。
- DI-2 WHEN 入库成功后凭课堂 id 再次读取，THE SYSTEM SHALL 仍报告 `hasKnowledgeBase` 为 `true`，原件与文档摘要仍在，且不回传全文。切块只属于该课堂，其他课堂不能检索到。
- DI-3 WHEN 对同一课堂再次入库且成功，THE SYSTEM SHALL 用新的切块与向量覆盖旧结果，知识库保持就绪，且该课仍然只有一份文档。
- DI-4 WHEN 课堂不存在、没有文档、原件丢失、解析后去掉空白不足 200 字、未提供向量模型配置，或向量维度不是 1024，THE SYSTEM SHALL 拒绝本次入库，返回可理解的错误并允许重试。不删除课堂与 PDF 原件。该课若尚未就绪，保持未就绪。
- DI-5 WHEN 入库在替换切块的过程中失败，THE SYSTEM SHALL 不得停在「知识库已就绪但切块不完整」。尚未成功过的课堂保持未就绪。
- DI-6 WHEN 用户进入有已保存 PDF 且知识库未就绪的草稿课堂生成页，THE SYSTEM SHALL 先展示资料处理状态并发起入库；确认成功前不启动大纲。成功后以就绪状态进入大纲流程，并使用当次向量配置进行检索。
- DI-7 WHEN 草稿课堂没有 PDF，或其知识库已就绪，THE SYSTEM SHALL 分别直接进入现有大纲流程或复用已就绪知识库；不为无 PDF 课堂要求向量配置，不因进入或刷新而重新入库。
- DI-8 WHEN 入库缺配置、解析或向量化失败，THE SYSTEM SHALL 显示可理解的失败信息、设置入口与显式重试，保留课堂和原件，不自动跳过 PDF 或启动大纲；保存配置本身不自动重试。
- DI-9 WHEN 入库期间刷新、断连或多个页面并发操作，THE SYSTEM SHALL 按服务端状态核对并恢复，不能将未知结果当作成功或确定失败；已完成结果可继续，重复或过期执行不得破坏完整知识库或覆盖较新的成功结果。
- DI-10 WHEN 已定稿的历史课堂有 PDF 但知识库未就绪，THE SYSTEM SHALL 按已有定稿恢复流程处理，不自动入库、不重新生成已确认大纲。

## 系统不变量

- 无 PDF 不得入库，也不得编造知识库。
- `hasKnowledgeBase` 为 `true` 只表示该课当前有一套完整切块与向量。
- 成功入库后，该文档的页数与解析全文已持久化。按课堂 id 读取时仍只带文档摘要，不回传全文。
- 每课至多一份 PDF。入库不新增文档，只更新这份文档的解析结果。
- 向量模型配置是自己的 Key、端点与模型名，只来自当次请求，不读取对话配置。缺失或维度不符则拒绝该次入库。
- 只读取该课堂上传目录内的原件。
- 持有课堂 id 即可入库。无登录。

## 非功能约束

- 失败信息须可理解，不得包含堆栈或密钥。
