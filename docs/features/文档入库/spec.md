# 文档入库

## 承诺

课堂已由「创建课堂」持久化。若该课保存了一份 PDF，本单元读取该原件，解析文本、按页切块并写入向量，使知识库就绪。无 PDF 的课不进入本单元。

入库是一次请求。请求成功返回前，知识库不得标为就绪。成功时返回课堂 id、文档 id、页数、去掉空白后的字符数、切块数，且 `hasKnowledgeBase` 为 `true`。向量模型配置只来自当次请求，不使用对话模型，也不读取服务端环境变量中的密钥。

解析正文去掉空白后少于 200 字，视为无法入库。写入的向量必须是 1024 维。

## 非目标

- 不接收新文件，不创建课堂，不重做 PDF 类型、空文件与 50MB 校验。
- 不提供模型设置界面。缺向量配置时只拒绝本次入库。
- 不生成大纲，不把全文送入大纲提示词，不抽取 PDF 中的图片。
- 不实现课堂讨论，也不在回答中展示文档引用。
- 不登录，不接受第二份 PDF、ZIP 或 PPTX。
- 生成预览页上的处理进度不在本篇。预览页展示留在同一功能上另行追加验收。

## 验收

- DI-1 WHEN 课堂已有一份已保存的 PDF，且当次请求带齐向量模型配置，THE SYSTEM SHALL 解析、按页切块、写入 1024 维向量，返回页数、去掉空白后的字符数与切块数，并将 `hasKnowledgeBase` 置为 `true`。此次不调用对话模型，不生成大纲。
- DI-2 WHEN 入库成功后凭课堂 id 再次读取，THE SYSTEM SHALL 仍报告 `hasKnowledgeBase` 为 `true`，原件与文档摘要仍在，且不回传全文。切块只属于该课堂，其他课堂不能检索到。
- DI-3 WHEN 对同一课堂再次入库且成功，THE SYSTEM SHALL 用新的切块与向量覆盖旧结果，知识库保持就绪，且该课仍然只有一份文档。
- DI-4 WHEN 课堂不存在、没有文档、原件丢失、解析后去掉空白不足 200 字、未提供向量模型配置，或向量维度不是 1024，THE SYSTEM SHALL 拒绝本次入库，返回可理解的错误并允许重试。不删除课堂与 PDF 原件。该课若尚未就绪，保持未就绪。
- DI-5 WHEN 入库在替换切块的过程中失败，THE SYSTEM SHALL 不得停在「知识库已就绪但切块不完整」。尚未成功过的课堂保持未就绪。

## 系统不变量

- 无 PDF 不得入库，也不得编造知识库。
- `hasKnowledgeBase` 为 `true` 只表示该课当前有一套完整切块与向量。
- 成功入库后，该文档的页数与解析全文已持久化。按课堂 id 读取时仍只带文档摘要，不回传全文。
- 每课至多一份 PDF。入库不新增文档，只更新这份文档的解析结果。
- 向量模型配置只来自当次请求。缺失或维度不符则拒绝该次入库。
- 只读取该课堂上传目录内的原件。
- 持有课堂 id 即可入库。无登录。

## 非功能约束

- 失败信息须可理解，不得包含堆栈或密钥。
