# 创建课堂

## 承诺

用户在首页填写输入并提交后，系统持久化一节课，并进入**以该课堂 id 标识**的生成预览。创建过程不调用模型。

输入是一层 `requirements`，另加可选 PDF：

```json
{
  "requirements": {
    "requirement": "必填",
    "userNickname": "可选",
    "userBio": "可选"
  }
}
```

首页须提供：

- 课程需求（必填）。
- 昵称与背景（均可省略）。
- 一份可选 PDF。
- 「开始生成」：仅在课程需求合格且当前没有进行中的提交时可点。本单元**不**因尚未配置模型而禁止提交。

无 PDF 时只提交 `requirements`。有 PDF 时同时提交该文件与同一份 `requirements`。成功后进入该课的生成预览；预览页在本单元只保证能凭课堂 id 识别这节课，不生成大纲、不入库。

`requirement` 去掉空白后不少于 10 字、不超过 10000 字。`userNickname` 与 `userBio` 可省略；去掉空白后为空视为未填。未知字段（含 `interactiveMode`）不作为建课输入保存。

## 非目标

- 不解析 PDF、不向量化、不把知识库标为就绪（属于文档入库）。
- 不生成大纲、不进入播放或讨论。
- 不调用模型。后端建课不要求事先配置模型。
- 不登录、不接受 ZIP / PPTX。
- 首页历史列表、搜索、折叠、重命名与删除由 [[历史课堂]] 独立定义，不在本单元交付范围。该单元已实施并完成本轮范围验证，证据与限制见其 plan；本单元仍保证凭课堂 id 刷新或再次打开恢复已保存的课堂。
- 不提供联网搜索、互动/PBL 模式、语音输入、课堂导入导出、幻灯片缩略图列表。

## 验收

- CC-1 WHEN 用户提交合法 `requirements.requirement` 且无 PDF，THE SYSTEM SHALL 持久化课堂、回显同一份 `requirements`，并进入该课的生成预览；此次不调用模型。
- CC-2 WHEN `requirements` 含非空 `userNickname` 和/或 `userBio`，THE SYSTEM SHALL 与提示词一并持久化；刷新或凭课堂 id 再次打开后仍能读回同一份 `requirements`。两者都为空时不编造学习者画像。
- CC-3 WHEN 用户附带合法 PDF（类型为 PDF、非空、不超过 50MB），THE SYSTEM SHALL 保存原件与元数据并进入该课的生成预览；知识库尚未就绪，不解析、不向量化。
- CC-4 WHEN 提示词缺失或不足 10 字、`requirements` 无法解析，或 PDF 非 PDF、为空、超过 50MB，THE SYSTEM SHALL 拒绝创建，展示可理解的错误并允许重试，且不留下半成品课堂。
- CC-5 WHEN 建课成功，THE SYSTEM SHALL 进入由服务端分配的课堂 id 所标识的生成预览；关闭页面后凭该 id 仍能读回已保存的课堂。不得仅凭未持久化的浏览器临时状态进入预览。
- CC-6 WHEN 用户在首页点击「开始生成」，THE SYSTEM SHALL 只接受合格的 `requirements`（及可选的合法 PDF）；不合格时停留在首页并展示错误；提交进行中不得重复创建。

## 约束

- 创建成功时课堂为草稿：知识库未就绪，尚未进入大纲或场景生成。
- 课程标题由提示词推导，不用昵称代替。
- 保存文件或写入课堂失败时，不得留下无法按 id 读回的半成品课堂。
- 进入生成预览所依据的标识必须是已持久化的课堂 id。
- 本单元不因未配置模型而拒绝建课。全链路完成后首页是否禁用「开始生成」，由 [[配置模型]] 与 [[intent]] 另行约定。

## 非功能约束

- 失败信息须可理解，不得包含堆栈或密钥。
- 创建请求失败时，用户可修改输入后再次提交。

## 验证

对照验收 ID 观察页面与按课堂 id 读回的结果。不要求自动化测试。创建过程中不得出现模型调用或文档入库。

| ID | 怎么验 | 通过 |
|---|---|---|
| CC-1 | 合法提示词、不上传 PDF，点击开始生成 | 是（[tasks](./tasks.md) V-1；`GET /api/stages/{id}` 读回） |
| CC-2 | 分别提交：仅昵称、仅背景、两者都有、两者都空白 | 是（tasks V-2） |
| CC-3 | 合法提示词 + 一份合法 PDF | 是（tasks V-3；`hasKnowledgeBase: false`） |
| CC-4 | 提示词短于 10 字；无法解析的需求；非 PDF、空文件、超过 50MB；只传 PDF 不传合格提示词 | 是（tasks V-4；不足 10 字时按钮禁用，选文件时 PDF 错误文案） |
| CC-5 | 成功建课后记下预览所对应的课堂 id，关掉页面再凭该 id 打开 | 是（tasks V-1；预览占位展示 id，持久化以 GET 为准） |
| CC-6 | 需求不足 10 字时看按钮与点击结果；合格需求连续快速点击开始生成 | 是（tasks V-4；`submitting` + `submitInFlightRef` 至跳转前） |

## 系统不变量

- 没有合格提示词不得建课。只上传 PDF 不能代替提示词。
- 提示词、昵称、背景分别落在课堂根实体上。不把 `requirements` 整包存成一列 JSON。
- 无登录。持有该课堂 id 即可访问该课堂。
- 昵称与背景都未填时，不写入学习者画像。
